# Code of Conduct

## বাংলা Python Handbook — Community Code of Conduct

We are committed to making the **বাংলা Python Handbook** community a welcoming, respectful, inclusive, and educational environment for everyone.

This Code of Conduct applies to all contributors, learners, maintainers, educators, developers, and visitors participating in this project.

---

## 🌟 Our Standards

We expect everyone in the community to:

- 🤝 Treat others with respect and kindness.
- 🧑‍💻 Welcome beginners and experienced developers equally.
- 📚 Encourage learning and knowledge sharing.
- 💡 Give constructive and useful feedback.
- 🗣️ Communicate professionally and respectfully.
- 🐍 Help others learn Python without unnecessary criticism.
- 🔍 Respect different approaches to solving programming problems.
- 📝 Clearly explain suggestions, corrections, and improvements.
- 🌍 Respect people from different countries, cultures, backgrounds, and experiences.
- ♿ Consider accessibility and inclusive participation.
- 🔐 Respect the privacy of other community members.

---

# 🚫 Unacceptable Behavior

The following behavior is not acceptable in this community:

- Harassment, bullying, or personal attacks.
- Discriminatory or hateful comments.
- Threats or intimidation.
- Trolling or deliberately disruptive behavior.
- Sexual harassment or inappropriate sexual content.
- Publishing someone's private or personal information without permission.
- Deliberately insulting beginners because of their skill level.
- Repeatedly dismissing legitimate questions without constructive feedback.
- Spam or excessive self-promotion.
- Deliberately submitting malicious code or harmful content.
- Deliberately introducing security vulnerabilities.
- Impersonating project maintainers or other contributors.
- Any other behavior that makes the community unsafe, hostile, or unwelcoming.

---
