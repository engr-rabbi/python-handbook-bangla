## 📚 About the Project

Python বর্তমানে অন্যতম জনপ্রিয় এবং বহুল ব্যবহৃত programming language।

কিন্তু অনেক বাংলা ভাষাভাষী শিক্ষার্থী English-only learning resources ব্যবহার করার সময় language barrier-এর মুখোমুখি হয়।

এই project-এর লক্ষ্য হলো:

> **Standard Python terminology এবং programming concepts ব্যবহার করে সহজ ও পরিষ্কার বাংলায় Python শেখানো।**

এই handbook এমনভাবে সাজানো হয়েছে যাতে একজন শিক্ষার্থী কোনো পূর্ব programming experience ছাড়াই Python শেখা শুরু করতে পারে।
