এই কোর্স সম্পর্কে

সম্পূর্ণ পাইথন কোর্স একটি ফ্রি, নিজের গতিতে চলার মতো ওয়েবসাইট, যা তৈরি হয়েছে একটি লক্ষ্যেই: প্রোগ্রামিংয়ে শূন্য অভিজ্ঞতা থাকা একজন মানুষকেও তার প্রথম print() থেকে শুরু করে একটি কার্যকর, বাস্তব Python অ্যাপ্লিকেশন পর্যন্ত পৌঁছে দিতে — যেখানে প্রতিটি ধারণা ব্যাখ্যা করা, অ্যানিমেট করা, অনুশীলন করা এবং কুইজে যাচাই করা হয়।

এটি যেভাবে তৈরি

পুরো সাইটটি স্ট্যাটিক HTML, CSS এবং সাধারণ JavaScript — একটি ছোট বিল্ড স্ক্রিপ্ট দিয়ে সুসংগঠিত Python ডেটা থেকে তৈরি, কোনো সার্ভার, ফ্রেমওয়ার্ক বা অ্যাকাউন্ট সিস্টেম ছাড়াই। প্রতিটি কোড উদাহরণ আপনার ব্রাউজারে সত্যিকারভাবে চলে Pyodide-এর মাধ্যমে, যা WebAssembly-এ কম্পাইল করা একটি সম্পূর্ণ CPython বিল্ড। আপনার অগ্রগতি এবং কুইজের ইতিহাস শুধু আপনার ব্রাউজারের লোকাল স্টোরেজেই থাকে।

কনটেন্টের কাঠামো

২০টি মডিউলের প্রতিটিই একই কাঠামো অনুসরণ করে: লার্নিং অবজেক্টিভ, সহজ ভাষায় ব্যাখ্যা, খুব সহজ থেকে চ্যালেঞ্জিং পর্যন্ত সাজানো চালানো-যায় এমন উদাহরণ, একটি ভিজ্যুয়াল ডায়াগ্রাম, সাধারণ ভুল, ভালো অভ্যাস, একটি অনুশীলনী, একটি চ্যালেঞ্জ এবং একটি কুইজ। এই সামঞ্জস্যতা ইচ্ছাকৃত — একটি লেসনের কাঠামো জানলে, বাকি বিশটিরও কাঠামো জানা হয়ে যায়।

নিজের কপি ডিপ্লয় করা

পুরো সাইটটি সাধারণ static ফাইল, তাই এটি GitHub Pages, Netlify, Vercel বা Cloudflare Pages-এ কোনো বিল্ড স্টেপ ছাড়াই ডিপ্লয় করা যায় — বিস্তারিত জানতে প্রজেক্ট সোর্সের README দেখুন।
