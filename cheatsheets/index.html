# commentএকটি সিঙ্গেল-লাইন কমেন্ট, Python এটি উপেক্ষা করে
"""docstring"""একটি মাল্টি-লাইন স্ট্রিং, প্রায়ই ফাংশন ডকুমেন্ট করতে ব্যবহৃত হয়

//ফ্লোর (পূর্ণসংখ্যা) ভাগ

স্ট্রিং

সিনট্যাক্সএটি যা করে
f"{name} is {age}"f-স্ট্রিং — টেক্সটের ভেতরে ভ্যারিয়েবল বসানো
s[0], s[-1]প্রথম ক্যারেক্টার, শেষ ক্যারেক্টার
s[1:4]ইনডেক্স 1 থেকে (4 বাদ দিয়ে) পর্যন্ত slice
s.strip()শুরু ও শেষের whitespace বাদ দেওয়া
s.upper() / s.lower()কেস পরিবর্তন করা
s.split(',')একটি separator দিয়ে লিস্টে ভাগ করা
s.replace(a, b)সব a-কে b দিয়ে বদলানো

লিস্ট

সিনট্যাক্সএটি যা করে
lst.append(x)শেষে x যোগ করা
lst.insert(i, x)i ইনডেক্সে x বসানো
lst.remove(x)প্রথম পাওয়া x বাদ দেওয়া
lst.pop()শেষ আইটেম বাদ দিয়ে রিটার্ন করা
lst.sort()লিস্ট নিজের জায়গায় সাজানো
len(lst)আইটেমের সংখ্যা
x in lstমেম্বারশিপ টেস্ট

ডিকশনারি

সিনট্যাক্সএটি যা করে
d["key"]key দিয়ে value খোঁজা (না থাকলে KeyError)
d.get("key", default)ফলব্যাক সহ নিরাপদ lookup
d.items()(key, value) জোড়া নিয়ে লুপ চালানো
d.keys() / d.values()শুধু key, বা শুধু value
"key" in dএকটি key আছে কিনা চেক করা

সিনট্যাক্সএটি যা করে
if / elif / elseশর্তের ভিত্তিতে branch করা
for x in iterable:জানা একটি সিকোয়েন্সে লুপ চালানো
while condition:শর্ত False না হওয়া পর্যন্ত লুপ চালানো
breakলুপ থেকে সঙ্গে সঙ্গে বের হওয়া
continueপরের ইটারেশনে চলে যাওয়া

def f(a, b=1):ডিফল্ট প্যারামিটার দিয়ে ফাংশন সংজ্ঞায়িত করা
return valueকলারের কাছে মান ফেরত দেওয়া
lambda x: x * 2ছোট, নামহীন ইনলাইন ফাংশন
*argsঅতিরিক্ত positional আর্গুমেন্ট একটি tuple-এ জমা করা
**kwargsঅতিরিক্ত keyword আর্গুমেন্ট একটি dictionary-এ জমা করা

OOP

সিনট্যাক্সএটি যা করে
class Dog:একটি ক্লাস সংজ্ঞায়িত করা
def __init__(self, name):কনস্ট্রাক্টর, অবজেক্ট তৈরি হলে চলে
self.name = nameএকটি instance অ্যাট্রিবিউট সেট করা
class Dog(Animal):একটি সুপারক্লাস থেকে ইনহেরিট করা
@propertyএকটি মেথডকে সাধারণ অ্যাট্রিবিউটের মতো কল করার সুযোগ দেওয়া

এক্সসেপশন

সিনট্যাক্সএটি যা করে
try / except ValueError:একটি নির্দিষ্ট এরর টাইপ ধরা
except Exception as e:একটি এরর ধরে তার মেসেজ দেখা
else:কোনো এক্সসেপশন না হলেই চলে
finally:সবসময় চলে, এরর হোক বা না হোক
raise ValueError("msg")ইচ্ছাকৃতভাবে একটি এক্সসেপশন তৈরি করা

ফাইল I/O

সিনট্যাক্সএটি যা করে
open("f.txt", "r")পড়ার জন্য খোলা (ডিফল্ট মোড)
open("f.txt", "w")লেখার জন্য খোলা (বিদ্যমান কনটেন্ট মুছে যাবে)
open("f.txt", "a")যুক্ত করার (append) জন্য খোলা
with open(...) as f:কাজ শেষে ফাইল স্বয়ংক্রিয়ভাবে বন্ধ হয়
f.read() / f.readlines()পুরো ফাইল পড়া, অথবা লাইনের লিস্ট হিসেবে

SQL (SQLite)

সিনট্যাক্সএটি যা করে
sqlite3.connect('app.db')একটি ডেটাবেস ফাইল খোলা (বা তৈরি করা)
cursor.execute(sql, params)? placeholder দিয়ে নিরাপদে একটি query চালানো
conn.commit()INSERT/UPDATE/DELETE পরিবর্তন সংরক্ষণ করা
cursor.fetchall()SELECT-এর সব row একটি tuple-এর লিস্ট হিসেবে পাওয়া
WHERE ... ORDER BY ...row ফিল্টার করা, তারপর সাজানো
