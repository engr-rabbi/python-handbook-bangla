মডিউল 12 — ক্লোজার ও ডেকোরেটর

যে ফাংশন মনে রাখে, এবং যে ফাংশন অন্য ফাংশনকে মুড়িয়ে দেয়।

পূর্বশর্ত: মডিউল ১১ — ফাংশনাল প্রোগ্রামিং

এই লেসন শেষে আপনি যা করতে পারবেন

  • একটি ক্লোজার কী এবং কেন একটি ইনার ফাংশন বাইরের ভ্যারিয়েবল 'মনে রাখতে' পারে তা ব্যাখ্যা করা
  • এমন একটি ফাংশন লেখা যা অন্য একটি ফাংশন রিটার্ন করে
  • @ সিনট্যাক্স দিয়ে একটি ডেকোরেটর লেখা ও প্রয়োগ করা

ধারণা ও সিনট্যাক্স

এই দুটো ধারণা প্রায় অন্য কিছুর চেয়ে বেশি শিক্ষানবিসকে বিভ্রান্ত করে, তাই ধীরে ধীরে এগোন।

একটি ক্লোজার ঘটে যখন একটি ইনার ফাংশন তার বেষ্টনকারী (বাইরের) ফাংশনের একটি ভ্যারিয়েবল ব্যবহার করে, এবং বাইরের ফাংশনটি চলা শেষ হয়ে যাওয়ার পরও সেটিতে অ্যাক্সেস রেখে দেয়। এভাবেই একটি ফাংশন তার নিজের ব্যক্তিগত মেমরি সাথে নিয়ে ঘুরতে পারে।

একটি ডেকোরেটর এমন একটি ফাংশন যা অন্য একটি ফাংশনকে ইনপুট হিসেবে নেয়, এবং একটি নতুন ফাংশন রিটার্ন করে যা সাধারণত মূল ফাংশনটি কল করে — সাথে আগে বা পরে অতিরিক্ত কিছু করে। উপরে @decorator সিনট্যাক্স আসলে my_function = decorator(my_function)-এর একটি সংক্ষিপ্ত রূপ মাত্র।

সিনট্যাক্স
def decorator(func):
    def wrapper(*args, **kwargs):
        # আগে কিছু করুন
        result = func(*args, **kwargs)
        # পরে কিছু করুন
        return result
    return wrapper
 
@decorator
def my_function():
    ...

উদাহরণ

একটি ফাংশন থেকে ফাংশন রিটার্ন করা খুব সহজ

একটি ফাংশন থেকে ফাংশন রিটার্ন করা
def make_multiplier(factor):
    def multiply(number):
        return number * factor
    return multiply
 
times3 = make_multiplier(3)
print(times3(10))
আউটপুট30

make_multiplier(3) একটি সম্পূর্ণ নতুন ফাংশন, multiply, রিটার্ন করে যেটা factor = 3 'মনে রেখেছে' — এটাই ক্লোজার।

একটি ক্লোজার যা ব্যক্তিগত অবস্থা ধরে রাখে মধ্যম

একটি ক্লোজার যা ব্যক্তিগত অবস্থা ধরে রাখে
def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter
 
count_up = make_counter()
print(count_up())
print(count_up())
print(count_up())
আউটপুট1 2 3

count থাকে make_counter-এর স্কোপের ভেতরে, কিন্তু counter() nonlocal দিয়ে সেটার একটি ব্যক্তিগত, স্থায়ী রেফারেন্স ধরে রাখে — প্রতিটি কল আগের মান মনে রাখে।

আপনার প্রথম ডেকোরেটর বাস্তব উদাহরণ

আপনার প্রথম ডেকোরেটর
def announce(func):
    def wrapper():
        print("Starting...")
        func()
        print("Done!")
    return wrapper
 
@announce
def say_hi():
    print("Hi!")
 
say_hi()
আউটপুটStarting... Hi! Done!

@announce হলো say_hi = announce(say_hi)-এর সংক্ষিপ্ত রূপ। say_hi() কল করলে এখন আসলে wrapper() চলে, যা মূল ফাংশনের আগে ও পরে আচরণ যোগ করে।

একটি ডেকোরেটর যা আর্গুমেন্ট গ্রহণ করে চ্যালেঞ্জ

একটি ডেকোরেটর যা আর্গুমেন্ট গ্রহণ করে
def announce(func):
    def wrapper(*args, **kwargs):
        print("Starting...")
        result = func(*args, **kwargs)
        print("Done!")
        return result
    return wrapper
 
@announce
def add(a, b):
    return a + b
 
print(add(2, 3))
আউটপুটStarting... Done! 5

wrapper-এ *args ও **kwargs ব্যবহার করলে ডেকোরেটরটি যেকোনো ফাংশনের উপর কাজ করে, সেটা যে আর্গুমেন্টই নেয় না কেন।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

একটি wrapper-এর ভেতরে func()-এর ফলাফল রিটার্ন করতে ভুলে গেলে মূল রিটার্ন মানটি নিঃশব্দে হারিয়ে যায়।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে 5-এর বদলে None প্রিন্ট হয়
def announce(func):
    def wrapper(*args, **kwargs):
        func(*args, **kwargs)  # ফলাফল ফেলে দেওয়া হলো!
    return wrapper
 
@announce
def add(a, b):
    return a + b
 
print(add(2, 3))
✓ সঠিক পদ্ধতি
সংশোধিত
def announce(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper
✓ ভালো অভ্যাস
  • একটি wrapper-এ সবসময় *args ও **kwargs গ্রহণ করুন, যাতে ডেকোরেটরটি যেকোনো ফাংশন সিগনেচারে কাজ করে।
  • wrapper থেকে সবসময় মূল ফাংশনের ফলাফল রিটার্ন করুন।
  • মূল ফাংশনের নাম ও docstring বজায় রাখতে আপনার wrapper-এ functools.wraps(func) ব্যবহার করুন (একটি ছোট কিন্তু পেশাদার স্পর্শ)।

অনুশীলনী ও চ্যালেঞ্জ

অনুশীলনী 1 — আউটপুট অনুমান করুন

এই কোডটি দেওয়া আছে
def outer():
    message = "hi"
    def inner():
        return message.upper()
    return inner
 
fn = outer()
print(fn())

এটি কী প্রিন্ট করবে?

💡 outer() চলা শেষ হয়ে গেলেও inner()-এর message-এ অ্যাক্সেস থাকে — এটাই ক্লোজার।

🏆 চ্যালেঞ্জ

timer_label নামে একটি ডেকোরেটর লিখুন যা মুড়িয়ে রাখা ফাংশন কল করার আগে '[LOG] Running <function name>' প্রিন্ট করে, তারপর একটি সহজ ফাংশনে এটি প্রয়োগ করুন।

  • *args/**kwargs ব্যবহার করুন যাতে এটি যেকোনো ফাংশনে কাজ করে
  • func.__name__ দিয়ে ফাংশনের নাম প্রিন্ট করুন
  • মূল ফাংশনের ফলাফল রিটার্ন করুন
💡 ইঙ্গিত প্রয়োজন?

প্রতিটি ফাংশন অবজেক্টের একটি __name__ অ্যাট্রিবিউট আছে।

🔍 একটি নমুনা সমাধান দেখুন
Python
def timer_label(func):
    def wrapper(*args, **kwargs):
        print(f"[LOG] Running {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
 
@timer_label
def add(a, b):
    return a + b
 
print(add(2, 3))

কুইজ

প্রতিটি প্রশ্নের উত্তর দিন, তারপর জমা দিয়ে নিজের স্কোর ও ব্যাখ্যা দেখুন।

1. একটি ক্লোজার কী?

কোনো প্যারামিটার নেই এমন একটি ফাংশন
একটি ইনার ফাংশন যা তার বেষ্টনকারী স্কোপ থেকে ভ্যারিয়েবলে অ্যাক্সেস ধরে রাখে
একটি ফাইল বন্ধ করার একটি পদ্ধতি
এক ধরনের লুপ
ক্লোজার একটি ইনার ফাংশনকে তার তৈরিকারী ফাংশনের ভ্যারিয়েবল 'মনে রাখতে' দেয়।

2. একটি ফাংশনের সংজ্ঞার উপরে @my_decorator আসলে কী করে?

কিছুই না, এটা শুধু একটি কমেন্ট
এটি ফাংশনটিকে my_decorator(function) দিয়ে বদলে দেয়
এটি ফাংশনটি মুছে দেয়
এটি ফাংশনটি তাৎক্ষণিক চালায়
@decorator হলো func = decorator(func)-এর সংক্ষিপ্ত রূপ।

3. একটি ডেকোরেটরের wrapper-এ কেন *args ও **kwargs গ্রহণ করা উচিত?

এটি বাধ্যতামূলক Python সিনট্যাক্স
যাতে এটি মুড়িয়ে রাখা ফাংশন যত আর্গুমেন্টই নিক না কেন কাজ করে
কোড দীর্ঘ করার জন্য
এর আসলে কোনো উদ্দেশ্য নেই
ভিন্ন ভিন্ন ফাংশন ভিন্ন আর্গুমেন্ট নেয় — *args/**kwargs ডেকোরেটরটিকে সার্বজনীন করে দেয়।

সারাংশ

  • একটি ক্লোজার হলো একটি ইনার ফাংশন যা তার বেষ্টনকারী ফাংশন থেকে ভ্যারিয়েবলে অ্যাক্সেস ধরে রাখে।
  • একটি ডেকোরেটর একটি ফাংশন নেয় এবং একটি নতুন ফাংশন রিটার্ন করে যা অতিরিক্ত আচরণ দিয়ে সেটাকে মুড়ে দেয়।
  • def-এর উপরে @decorator হলো func = decorator(func)-এর সংক্ষিপ্ত রূপ।
  • একটি ডেকোরেটরের wrapper-এ সবসময় *args/**kwargs ফরওয়ার্ড করুন এবং ইনার ফলাফল রিটার্ন করুন।
