মডিউল 04 — কন্ট্রোল ফ্লো ও লুপ

আপনার প্রোগ্রামকে সিদ্ধান্ত নিতে ও কাজ পুনরাবৃত্তি করতে শেখানো — if/else, while, এবং for।

পূর্বশর্ত: মডিউল ০৩ — স্ট্রিং ও ইউজার ইনপুট

এই লেসন শেষে আপনি যা করতে পারবেন

  • if / elif / else এবং and/or/not অপারেটর দিয়ে প্রোগ্রামের লজিক শাখায়িত করা
  • একটি নিরাপদ exit condition সহ while লুপ দিয়ে কোড পুনরাবৃত্তি করা
  • for লুপ ও range() দিয়ে iterate করা, step আর্গুমেন্ট সহ
  • break ও continue দিয়ে লুপের প্রবাহ নিয়ন্ত্রণ করা

ধারণা ও সিনট্যাক্স

কন্ট্রোল ফ্লো হলো সেই বিষয় যা নির্দেশের একটি তালিকাকে এমন একটি প্রোগ্রামে পরিণত করে যা আসলেই সিদ্ধান্ত নিতে পারে। দুটি টুল প্রায় সব কাজ করে: if স্টেটমেন্ট (কিছু কোড চালাবেন কিনা ঠিক করা) এবং লুপ (কোনো কোড কতবার চালাবেন ঠিক করা)।

একটি for লুপ ব্যবহার করা হয় যখন আপনি জানেন আপনি কী নিয়ে iterate করছেন — সংখ্যার একটি range, একটি স্ট্রিং, একটি লিস্ট। একটি while লুপ ব্যবহার করা হয় যখন আপনি "কোনো শর্ত বদলানো পর্যন্ত" পুনরাবৃত্তি করতে চান, যা অনির্দিষ্ট সংখ্যক বার ঘটতে পারে — যেমন একজন ব্যবহারকারী সঠিক ইনপুট না দেওয়া পর্যন্ত বারবার জিজ্ঞেস করা।

উদাহরণ

if / elif / else খুব সহজ

if / elif / else
age = 20
if age < 13:
    print("Child")
elif age < 20:
    print("Teenager")
else:
    print("Adult")
আউটপুটAdult

Python উপর থেকে নিচে প্রতিটি শর্ত পরীক্ষা করে এবং প্রথম যেটি True হয় তার ব্লক চালায়, তারপর বাকিগুলো এড়িয়ে যায়।

একাধিক শর্ত একসাথে সহজ

একাধিক শর্ত একসাথে
age = 25
has_id = True
if age >= 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")
আউটপুটEntry allowed

and-এর জন্য দুটোই True লাগবে; or-এর জন্য একটি হলেই যথেষ্ট; not একটি বুলিয়ানকে উল্টে দেয়।

চলতি টোটাল সহ while লুপ মধ্যম

চলতি টোটাল সহ while লুপ
total = 0
n = 1
while n <= 5:
    total = total + n
    n = n + 1
print(total)
আউটপুট15

n <= 5 যতক্ষণ True থাকে, লুপ চলতে থাকে। প্রতিটি পাসে total-এ n যুক্ত হয়, তারপর n বাড়ে — এভাবেই 1+2+3+4+5 যোগ করা হয়।

একটি স্ট্রিংয়ের উপর for লুপ সহজ

একটি স্ট্রিংয়ের উপর for লুপ

    print(letter)
আউটপুটP y !

একটি for লুপ সরাসরি যেকোনো সিকোয়েন্সের উপর iterate করতে পারে — এমনকি একটি স্ট্রিংও, ক্যারেক্টার বাই ক্যারেক্টার।

break ও continue বাস্তব উদাহরণ

break ও continue
for number in range(10):
    if number == 7:
        break
    if number % 2 != 0:
        continue
    print(number)
আউটপুট0 2 4 6

continue সরাসরি পরের ইটারেশনে চলে যায় (এখানে বিজোড় সংখ্যা এড়িয়ে); number 7-এ পৌঁছালে break পুরো লুপ থেকে বের করে দেয়।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

✓ ভালো অভ্যাস
  • যখন আপনি জানেন কতবার পুনরাবৃত্তি হবে বা একটি সংগ্রহের উপর iterate করছেন, তখন for ব্যবহার করুন।
  • শেষ হওয়ার শর্ত আগে থেকে জানা না গেলে তখনই while ব্যবহার করুন।
  • লুপ বডি ছোট রাখুন — ভেতরের লজিক কয়েক লাইনের বেশি হলে একটি ফাংশনে আলাদা করে নিন (DRY নীতি: Don't Repeat Yourself)।
  • নিশ্চিত করুন যে প্রতিটি while লুপের একদিন False হওয়ার একটা উপায় আছে।

5. while লুপের বদলে কখন for লুপ পছন্দ করা উচিত?

ইটারেশনের সংখ্যা অজানা হলে
একটি জানা সংগ্রহ বা range-এর উপর iterate করার সময়
কখনোই না — while সবসময় ভালো
শুধু ফাংশনের ভেতরে
একটি জানা আকারের কিছুর উপর iterate করার সময় for লুপ সবচেয়ে উপযোগী।

সারাংশ

  • if/elif/else শর্তের ভিত্তিতে প্রোগ্রামকে শাখায়িত করে, উপর থেকে নিচে পরীক্ষা করে।
  • and, or, এবং not বুলিয়ান শর্তগুলো একসাথে মেলায়।
  • while একটি শর্ত False না হওয়া পর্যন্ত পুনরাবৃত্তি করে — নিশ্চিত করুন সেটি একদিন হবে।
  • for একটি জানা সিকোয়েন্সের উপর iterate করে; break আগেই বের করে দেয়, continue এগিয়ে যায়।
