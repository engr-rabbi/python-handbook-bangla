মডিউল 08 — ডিকশনারি

পজিশনের বদলে নাম দিয়ে কিছু খোঁজা — key/value সংরক্ষণ।

পূর্বশর্ত: মডিউল ০৭ — টাপল

এই লেসন শেষে আপনি যা করতে পারবেন

  • ডিকশনারি তৈরি করা এবং key দিয়ে মান অ্যাক্সেস, যোগ ও আপডেট করা
  • key, value, এবং key-value জোড়ার উপর লুপ চালানো
  • থাকতে পারে বা না থাকতে পারে এমন একটি key নিরাপদে খুঁজতে get() ব্যবহার করা
  • একটি ডিকশনারি দিয়ে word-frequency counter তৈরি করা

ধারণা ও সিনট্যাক্স

একটি ডিকশনারি ডেটাকে key → value জোড়া হিসেবে সংরক্ষণ করে, যা একটি নম্বরযুক্ত পজিশনের বদলে অর্থবহ একটি নাম দিয়ে কিছু খুঁজে পেতে দেয়। যেখানে একটি লিস্ট উত্তর দেয় "পজিশন 2-এ কী আছে?", একটি ডিকশনারি উত্তর দেয় "'age' key-এর নিচে কী সংরক্ষিত আছে?" — একজন ব্যবহারকারীর প্রোফাইল বা একটি পণ্যের তালিকার মতো বাস্তব রেকর্ডের জন্য এটা অনেক বেশি স্বাভাবিক একটি পদ্ধতি।

সিনট্যাক্স
person = {"name": "Ada", "age": 28}
person["age"]           # 28
person["email"] = "a@x.com"  # নতুন key যোগ করা
person.get("phone", "N/A")   # নিরাপদ lookup

উদাহরণ

একটি ডিকশনারি তৈরি ও পড়া খুব সহজ

একটি ডিকশনারি তৈরি ও পড়া
person = {"name": "Ada", "age": 28}
print(person["name"])
print(person["age"])
আউটপুটAda 28

স্কয়ার ব্র্যাকেটে একটি ইনডেক্স না দিয়ে একটি key দিলে সংশ্লিষ্ট মানটি ফিরিয়ে আনে।

যোগ ও আপডেট করা সহজ

যোগ ও আপডেট করা
person = {"name": "Ada"}
person["age"] = 28
person["age"] = 29
print(person)
আউটপুট{'name': 'Ada', 'age': 29}

একটি নতুন key-এ assign করলে সেটি যোগ হয়; একটি বিদ্যমান key-এ assign করলে সেটি ওভাররাইট হয়।

নিরাপদ lookup-এর জন্য get() মধ্যম

নিরাপদ lookup-এর জন্য get()
person = {"name": "Ada"}
print(person.get("age", "Unknown"))
আউটপুটUnknown

person["age"] KeyError দিত কারণ 'age' নামে কোনো key নেই। get(key, default) ক্র্যাশ না করে ডিফল্ট মান ফিরিয়ে দেয়।

একটি ডিকশনারির উপর লুপ চালানো বাস্তব উদাহরণ

একটি ডিকশনারির উপর লুপ চালানো
prices = {"apple": 0.5, "bread": 2.3, "milk": 1.2}
for item, price in prices.items():
    print(f"{item}: ${price}")
আউটপুটapple: $0.5 bread: $2.3 milk: $1.2

.items() লুপের প্রতিটি পাসে key এবং value দুটোই একসাথে দেয়।

শব্দ গোনার প্রোগ্রাম চ্যালেঞ্জ

শব্দ গোনার প্রোগ্রাম
text = "the cat sat on the mat the cat ran"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1
print(counts)
আউটপুট{'the': 3, 'cat': 2, 'sat': 1, 'on': 1, 'mat': 1, 'ran': 1}

এই ক্লাসিক প্যাটার্ন get(word, 0) ব্যবহার করে কোনো নতুন শব্দকে 0 থেকে শুরু করায়, তারপর প্রতিবার আবার দেখা গেলে 1 যোগ করে।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

একটি অনুপস্থিত key স্কয়ার ব্র্যাকেট দিয়ে অ্যাক্সেস করলে সুন্দরভাবে ফেইল না করে প্রোগ্রাম ক্র্যাশ করে।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে KeyError: 'age'
person = {"name": "Ada"}
print(person["age"])
✓ সঠিক পদ্ধতি
সংশোধিত
person = {"name": "Ada"}
print(person.get("age", "Not specified"))
✓ ভালো অভ্যাস
  • একটি key না-ও থাকতে পারে এমন যেকোনো জায়গায় .get(key, default) ব্যবহার করুন।
  • কোনো key ধরে নেওয়ার আগে in দিয়ে চেক করুন: if "age" in person:।
  • মানগুলো স্বাভাবিকভাবে সম্পর্কিত হলে, যেমন একটি নাম ও তার বয়স, প্যারালাল লিস্টের বদলে ডিকশনারি বেশি পছন্দ করুন।
  • লুপে key ও value দুটোই লাগলে .items() ব্যবহার করুন।

অনুশীলনী ও চ্যালেঞ্জ

অনুশীলনী 1 — ফাঁকা পূরণ করুন

এই কোডটি দেওয়া আছে
stock = {"pencil": 12}
count = ____________________

লাইনটি এমনভাবে সম্পূর্ণ করুন যাতে stock["pen"] যদি ইতিমধ্যে একটি key না থাকে, তাহলে ক্র্যাশ না করে নিরাপদে 0 ফিরিয়ে দেয়।

💡 get() key এবং একটি fallback ডিফল্ট মান নেয়।
Python
stock.get("pen", 0)

🏆 চ্যালেঞ্জ

একটি সহজ কন্টাক্ট বুক তৈরি করুন: নাম থেকে ফোন নাম্বারের একটি ডিকশনারি। তিনটি কন্টাক্ট যোগ করুন, তারপর get() দিয়ে একটি খুঁজুন, 'Not found'-কে fallback হিসেবে দিয়ে এমন একটি নাম যা বইতে নেই।

  • কমপক্ষে ৩টি name→phone জোড়া সংরক্ষণ করুন
  • lookup-এর জন্য .get() ব্যবহার করুন
  • একটি সফল ও একটি অসফল lookup-এর ফলাফল প্রিন্ট করুন

কুইজ

প্রতিটি প্রশ্নের উত্তর দিন, তারপর জমা দিয়ে নিজের স্কোর ও ব্যাখ্যা দেখুন।

1. একটি key না-ও থাকতে পারে এমন key নিরাপদে কীভাবে খুঁজবেন?

4. "age" key না থাকলে person["age"] কোন এরর দেয়?

IndexError
TypeError
KeyError

অনুপস্থিত ডিকশনারি key KeyError দেয়।

সারাংশ

  • ডিকশনারি key → value জোড়া সংরক্ষণ করে, পজিশনের বদলে key দিয়ে খোঁজা হয়।
  • স্কয়ার-ব্র্যাকেট অ্যাক্সেস অনুপস্থিত key-তে ক্র্যাশ করে; .get(key, default) করে না।
  • বিদ্যমান key-তে assign করলে সেটি আপডেট হয়; নতুন key-তে করলে যোগ হয়।
  • .items() key ও value একসাথে লুপ করার সুযোগ দেয়।
