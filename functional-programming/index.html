মডিউল 11 — ফাংশনাল প্রোগ্রামিং ও অ্যাডভান্সড ফাংশন

ল্যাম্বডা এক্সপ্রেশন, map/filter, এবং ফাংশনকে সাধারণ মানের মতো ট্রিট করা।

পূর্বশর্ত: মডিউল ০৯ — সেট ও কম্প্রিহেনশন

এই লেসন শেষে আপনি যা করতে পারবেন

  • lambda দিয়ে ছোট নামহীন ফাংশন লেখা
  • map() ও filter() দিয়ে একটি সিকোয়েন্স রূপান্তর ও ফিল্টার করা
  • zip() দিয়ে সিকোয়েন্স জোড়া বানানো এবং enumerate() দিয়ে পজিশন ট্র্যাক করা
  • any() ও all() ব্যবহার করা এবং একটি কাস্টম sort key তৈরি করা

ধারণা ও সিনট্যাক্স

Python-এ ফাংশনও মান — আপনি একটি ফাংশনকে একটি ভ্যারিয়েবলে রাখতে পারেন, অন্য একটি ফাংশনে পাস করতে পারেন, বা একটি ফাংশন থেকে রিটার্ন করতে পারেন, ঠিক একটি সংখ্যা বা স্ট্রিংয়ের মতোই। ফাংশনাল প্রোগ্রামিং এই বিষয়টা ব্যবহার করে: একটি লিস্টের প্রতিটি আইটেম রূপান্তর করার জন্য একটি লুপ লেখার বদলে, আপনি map()-এর মতো একটি টুলে একটি ছোট ফাংশন হাতে দিয়ে দিন এবং সেটাকে সবখানে প্রয়োগ করতে দিন।

lambda আপনাকে এক লাইনেই একটি ছোট, নামহীন ফাংশন লিখতে দেয়, ঠিক সেই পরিস্থিতিগুলোর জন্য যেখানে পুরোপুরি একটি আলাদা ফাংশন def দিয়ে সংজ্ঞায়িত করা বাড়াবাড়ি হয়ে যেত।

সিনট্যাক্স
double = lambda x: x * 2
list(map(double, numbers))
list(filter(lambda x: x > 0, numbers))

উদাহরণ

lambda মৌলিক ধারণা খুব সহজ

lambda মৌলিক ধারণা
square = lambda x: x * x
print(square(5))
আউটপুট25

lambda x: x * x হলো def square(x): return x * x-এর সমতুল্য একটি নামহীন ফাংশন — স্পষ্টতার জন্য এখানে একটি নাম দেওয়া হয়েছে।

map() সহজ

map()
numbers = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, numbers))
print(doubled)
আউটপুট[2, 4, 6, 8]

map(function, iterable) প্রতিটি আইটেমে function প্রয়োগ করে এবং একটি iterator রিটার্ন করে, যাকে list() একটি আসল লিস্টে রূপান্তর করে।

filter() সহজ

filter()
numbers = [1, -2, 3, -4, 5]
positives = list(filter(lambda x: x > 0, numbers))
print(positives)
আউটপুট[1, 3, 5]

filter(function, iterable) শুধু সেই আইটেমগুলো রাখে যেখানে function True রিটার্ন করে।

enumerate() ও zip() মধ্যম

enumerate() ও zip()
names = ["Ada", "Sam", "Lee"]
scores = [92, 85, 78]
for i, name in enumerate(names, start=1):
    print(i, name)
for name, score in zip(names, scores):
    print(f"{name}: {score}")
আউটপুট1 Ada 2 Sam 3 Lee Ada: 92 Sam: 85 Lee: 78

enumerate() প্রতিটি আইটেমকে তার পজিশনের সাথে জোড়া দেয়; zip() দুই (বা তার বেশি) সিকোয়েন্সে একসাথে, আইটেম বাই আইটেম হাঁটে।

any(), all(), এবং key সহ sorted বাস্তব উদাহরণ

any(), all(), এবং key সহ sorted
scores = [55, 82, 40, 91]
print(any(s > 90 for s in scores))
print(all(s > 30 for s in scores))
print(sorted(scores, key=lambda s: -s))
আউটপুটTrue True [91, 82, 55, 40]

কমপক্ষে একটি আইটেম শর্ত পূরণ করলে any() True হয়; প্রতিটি আইটেমের জন্য শর্ত সত্য হতে হলে all() লাগবে। sorted(..., key=...) একটি কাস্টম নিয়ম দিয়ে সাজানোর ক্রম নিয়ন্ত্রণ করে।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

Python 3-এ map() ও filter() lazy iterator রিটার্ন করে, লিস্ট নয় — একটি সরাসরি প্রিন্ট করলে মান নয়, একটি মেমরি রেফারেন্স দেখা যায়।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে <map object at 0x...>-এর মতো কিছু প্রিন্ট হয়, মানগুলো না
result = map(lambda x: x*2, [1, 2, 3])
print(result)
✓ সঠিক পদ্ধতি
সংশোধিত
result = list(map(lambda x: x*2, [1, 2, 3]))
print(result)
✓ ভালো অভ্যাস
  • যদি পড়তে বেশি স্পষ্ট মনে হয় তাহলে map()/filter()-এর চেয়ে একটি list comprehension বেশি পছন্দ করুন — দুটোই বৈধ, প্রচলিত Python।
  • lambda-কে একটি সাধারণ এক্সপ্রেশনের মধ্যে সীমিত রাখুন; লজিক বড় হলে একটি সাধারণ def ফাংশন ব্যবহার করুন।
  • একের বেশি বার ব্যবহার করার প্রয়োজন হলে map()/filter()-এর ফলাফল list()-এ (বা tuple()/set()) মুড়িয়ে দিন।

অনুশীলনী ও চ্যালেঞ্জ

অনুশীলনী 1 — আউটপুট অনুমান করুন

এই কোডটি দেওয়া আছে
nums = [10, 15, 20, 25]
result = list(filter(lambda n: n % 10 == 0, nums))
print(result)

🏆 চ্যালেঞ্জ

পণ্যের একটি লিস্ট (প্রতিটি ডিকশনারিতে 'name' ও 'price' আছে) দেওয়া থাকলে, sorted() এবং একটি lambda key ব্যবহার করে সবচেয়ে সস্তা থেকে সবচেয়ে দামি ক্রমে প্রিন্ট করুন।

  • key=lambda সহ sorted() ব্যবহার করুন
  • 'price' ফিল্ড অনুযায়ী সাজান
  • প্রতিটি পণ্যের নাম ও দাম আলাদা লাইনে প্রিন্ট করুন
💡 ইঙ্গিত প্রয়োজন?

key=lambda p: p["price"]

🔍 একটি নমুনা সমাধান দেখুন
Python
products = [{"name": "Mouse", "price": 25}, {"name": "Keyboard", "price": 60}, {"name": "Cable", "price": 8}]
for p in sorted(products, key=lambda p: p["price"]):
    print(p["name"], p["price"])

কুইজ

প্রতিটি প্রশ্নের উত্তর দিন, তারপর জমা দিয়ে নিজের স্কোর ও ব্যাখ্যা দেখুন।

1. lambda x: x * 2 কী তৈরি করে?

একটি ভ্যারিয়েবল
একটি ছোট নামহীন ফাংশন
একটি list comprehension
একটি লুপ

2. filter() একটি সিকোয়েন্স থেকে কী রাখে?

প্রতিটি আইটেম
শুধু সেই আইটেম যেখানে ফাংশন True রিটার্ন করে
শুধু প্রথম আইটেম
শুধু ডুপ্লিকেট
filter() টেস্ট ফাংশন পাস করে এমন আইটেমগুলো রাখে।

3. zip(names, scores) কী তৈরি করে?

একটি একক মিলিত লিস্ট
প্রতিটি সিকোয়েন্স থেকে সংশ্লিষ্ট আইটেম জোড়া লাগিয়ে
একটি ডিকশনারি
দৈর্ঘ্য ভিন্ন হলে একটি এরর
zip() প্রতিটি iterable থেকে পজিশনভিত্তিকভাবে আইটেম জোড়া দেয়।

4. map()-কে প্রায়ই list()-এ মুড়ে দিতে হয় কেন?

map() একটি স্ট্রিং রিটার্ন করে
map() একটি lazy iterator রিটার্ন করে, লিস্ট নয়
এটি বাধ্যতামূলক সিনট্যাক্স
আসলে এটার প্রয়োজন নেই
map() ও filter() lazy — list() তাদের মানগুলো তৈরি করতে বাধ্য করে।

সারাংশ

  • Python-এ ফাংশন মান — এগুলো অন্য কোনো ডেটার মতোই ঘোরানো যায়।
  • lambda এক-বারের ব্যবহারের জন্য ছোট, নামহীন ফাংশন তৈরি করে।
  • map() প্রতিটি আইটেম রূপান্তর করে; filter() শুধু মিলে যাওয়া আইটেম রাখে।
  • সিকোয়েন্স নিয়ে কাজ করার সময় enumerate(), zip(), any(), ও all() প্রায়ই কাজে লাগে।
