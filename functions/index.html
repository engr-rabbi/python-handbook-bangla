মডিউল 05 — ফাংশন

লজিককে পুনর্ব্যবহারযোগ্য, নামযুক্ত ব্লকে গুছিয়ে রাখা — সুসংগঠিত কোডের দিকে সবচেয়ে বড় পদক্ষেপ।

পূর্বশর্ত: মডিউল ০৪ — কন্ট্রোল ফ্লো ও লুপ

এই লেসন শেষে আপনি যা করতে পারবেন

  • def দিয়ে একটি ফাংশন সংজ্ঞায়িত করা এবং আর্গুমেন্ট দিয়ে কল করা
  • একটি ফাংশনের ভেতরে return ও print-এর পার্থক্য বোঝা
  • ডিফল্ট প্যারামিটার মান ব্যবহার করা
  • লোকাল ও গ্লোবাল ভ্যারিয়েবল স্কোপের পার্থক্য ব্যাখ্যা করা

ধারণা ও সিনট্যাক্স

একটি ফাংশন হলো একটি নামযুক্ত, পুনর্ব্যবহারযোগ্য কোডের ব্লক যা একটি কাজ সম্পন্ন করে। আপনি ইতিমধ্যেই একটি ব্যবহার করে ফেলেছেন — print() — নিজে না লিখেই। একবার নিজে লিখতে শিখে গেলে, যে কোনো লজিকের ব্লক যা আপনি অন্যথায় কপি-পেস্ট করতেন, তাকে একটি নাম দিয়ে যতবার ইচ্ছা কল করতে পারবেন।

শিক্ষানবিসদের জন্য সবচেয়ে গুরুত্বপূর্ণ পার্থক্য হলো return বনাম print: print() শুধু স্ক্রিনে কিছু দেখায় এবং তা চিরতরে হারিয়ে যায়; return কল করা জায়গায় একটি মান ফিরিয়ে দেয়, তাই সেই মানটি সংরক্ষণ করা, অন্য জায়গায় পাস করা, বা আরও হিসাবের জন্য ব্যবহার করা যায়।

সিনট্যাক্স
def function_name(parameter1, parameter2="default"):
    """Optional docstring explaining what this does."""
    result = parameter1 + parameter2
    return result

প্যারামিটার ও রিটার্ন সহজ

প্যারামিটার ও রিটার্ন
def add(a, b):
    return a + b
 
total = add(4, 5)
print(total)
আউটপুট9

a এবং b হলো প্যারামিটার — placeholder, যা কল করার সময় 4 এবং 5 আর্গুমেন্ট দিয়ে পূরণ হয়। return যোগফলটি ফিরিয়ে দেয় যাতে total-এ সংরক্ষণ করা যায়।

ডিফল্ট প্যারামিটার মধ্যম

ডিফল্ট প্যারামিটার
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"
 
print(greet("Sam"))
print(greet("Sam", "Hi"))
আউটপুটHello, Sam! Hi, Sam!

greeting-এর একটি ডিফল্ট মান আছে, তাই এটি ঐচ্ছিক। দ্বিতীয় একটি আর্গুমেন্ট দিলে ডিফল্টটি বদলে যায়।

একটি ফাংশন অন্য ফাংশনকে কল করছে বাস্তব উদাহরণ

একটি ফাংশন অন্য ফাংশনকে কল করছে
def square(n):
    return n * n
 
def sum_of_squares(a, b):
    return square(a) + square(b)
 
print(sum_of_squares(3, 4))
আউটপুট25

ফাংশন অন্য ফাংশনকে কল করতে পারে — এভাবেই জটিল প্রোগ্রামগুলো ছোট, পরীক্ষা করার মতো টুকরোয় সুসংগঠিত থাকে।

রিকার্শন: ফিবোনাচি চ্যালেঞ্জ

রিকার্শন: ফিবোনাচি
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)
 
for i in range(8):
    print(fibonacci(i), end=" ")
আউটপুট0 1 1 2 3 5 8 13

একটি রিকার্সিভ ফাংশন নিজেকেই ছোট ইনপুট দিয়ে কল করে, যতক্ষণ না একটি 'base case'-এ পৌঁছায় (এখানে, n <= 1) যা রিকার্শন থামিয়ে দেয়।

ভিজ্যুয়াল ব্যাখ্যা

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

একটি ফাংশন কল হওয়া, চলা, এবং রিটার্ন করা দেখুন

নিচের নিয়ন্ত্রণগুলো দিয়ে এই উদাহরণটি এক লাইন করে চালিয়ে দেখুন এবং ইন্টারপ্রিটারের মেমরি লাইভ পরিবর্তন হতে দেখুন।

অনুশীলনী 1 — কোড লিখুন

is_even(n) নামে একটি ফাংশন লিখুন যা n জোড় হলে True এবং না হলে False রিটার্ন করে। is_even(7) কী রিটার্ন করবে?

💡 একটি সংখ্যা জোড় হয় যদি n % 2 == 0 হয়।
Python
def is_even(n):
    return n % 2 == 0
 
print(is_even(7))

🏆 চ্যালেঞ্জ

greatest(a, b, c) নামে একটি ফাংশন লিখুন যা তিনটি সংখ্যার মধ্যে সবচেয়ে বড়টি রিটার্ন করে, বিল্ট-ইন max() ব্যবহার না করে।

  • শুধু if/elif/else তুলনা ব্যবহার করুন
  • টাই (সমান সংখ্যা) যুক্তিসঙ্গতভাবে সামাল দিন
  • কমপক্ষে ৩টি ভিন্ন কল দিয়ে পরীক্ষা করুন
💡 ইঙ্গিত প্রয়োজন?

প্রথমে ধরে নিন a-ই সবচেয়ে বড়, তারপর সেটাকে b-এর সাথে, তারপর c-এর সাথে তুলনা করুন।

🔍 একটি নমুনা সমাধান দেখুন
Python
def greatest(a, b, c):
    biggest = a
    if b > biggest:
        biggest = b
    if c > biggest:
        biggest = c
    return biggest
 
print(greatest(4, 9, 2))

base case-ই সেই শর্ত যা ফাংশনকে চিরকাল নিজেকে কল করা থেকে থামায়।

5. কোনো explicit return স্টেটমেন্ট না থাকলে একটি ফাংশন কী রিটার্ন করে?

0
একটি খালি স্ট্রিং
None
এটি একটি এরর দেয়
কোনো return স্টেটমেন্ট না চললে Python ফাংশন implicit-ভাবে None রিটার্ন করে।

সারাংশ

  • def একটি পুনর্ব্যবহারযোগ্য, নামযুক্ত কোড ব্লক তৈরি করে; প্যারেন্থিসিসের ভেতরে তার প্যারামিটার থাকে।
  • return কলারের কাছে একটি মান ফিরিয়ে দেয়; print শুধু তা দেখায়।
  • ডিফল্ট প্যারামিটার মান আর্গুমেন্টকে ঐচ্ছিক করে দেয়।
  • একটি ফাংশনের ভেতরে তৈরি হওয়া ভ্যারিয়েবল লোকাল, এবং রিটার্ন হওয়ার সাথে সাথে হারিয়ে যায়।
