শব্দকোষ

কোর্সের প্রতিটি গুরুত্বপূর্ণ পরিভাষা, এক জায়গায় খুঁজে পাওয়ার মতো করে সাজানো — উপরের সার্চ বার দিয়ে সরাসরি কোনো সংজ্ঞায় চলে যান।

A

API → সম্পর্কিত লেসন
একটি সফটওয়্যারের অন্য একটি সফটওয়্যারের সাথে কথা বলার নির্ধারিত পদ্ধতি — যেমন কোনো ওয়েবসাইটের সার্ভার থেকে ডেটা রিকোয়েস্ট করা।
Argument (আর্গুমেন্ট) → সম্পর্কিত লেসন
ফাংশন কল করার সময় আপনি যে আসল মান পাঠান, যেমন add(5, 3)-এর 5।
Attribute (অ্যাট্রিবিউট) → সম্পর্কিত লেসন
একটি অবজেক্টে সংরক্ষিত ডেটার এক টুকরো, ডট নোটেশন দিয়ে অ্যাক্সেস করা হয়, যেমন dog.name।

B

Boolean (বুলিয়ান) → সম্পর্কিত লেসন
একটি মান যা হয় True নয় False।

C

Class (ক্লাস) → সম্পর্কিত লেসন
অবজেক্ট তৈরির একটি ব্লুপ্রিন্ট, যা তার অ্যাট্রিবিউট ও মেথড সংজ্ঞায়িত করে।
Comprehension (কম্প্রিহেনশন) → সম্পর্কিত লেসন
একটি বিদ্যমান iterable থেকে এক লাইনে নতুন লিস্ট, dict বা set তৈরির সংক্ষিপ্ত সিনট্যাক্স।
CRUD → সম্পর্কিত লেসন
ডেটাবেসের চারটি মৌলিক অপারেশনের সংক্ষিপ্ত রূপ: Create, Read, Update, Delete।

D

Decorator (ডেকোরেটর) → সম্পর্কিত লেসন
একটি ফাংশন যা অন্য একটি ফাংশনকে মুড়িয়ে (wrap করে) নতুন আচরণ যোগ করে, @decorator সিনট্যাক্স দিয়ে প্রয়োগ করা হয়।
Dictionary (ডিকশনারি) → সম্পর্কিত লেসন
key → value জোড়ার একটি অক্রমিক (unordered) সংগ্রহ, key দিয়ে খোঁজা হয়।

E

Exception (এক্সসেপশন) → সম্পর্কিত লেসন
এক্সিকিউশনের সময় দেখা দেওয়া একটি এরর অবস্থা, যা try/except দিয়ে ধরা ও সামাল দেওয়া যায়।

F

Function (ফাংশন) → সম্পর্কিত লেসন
একটি নামযুক্ত, পুনর্ব্যবহারযোগ্য কোডের ব্লক যা ইনপুট নিতে পারে এবং একটি আউটপুট রিটার্ন করতে পারে।

G

Generator (জেনারেটর) → সম্পর্কিত লেসন
yield ব্যবহার করা একটি ফাংশন, যা একসাথে সব না দিয়ে একটি একটি মান তৈরি করে, চাহিদামতো।

I

Immutable (অপরিবর্তনীয়) → সম্পর্কিত লেসন
তৈরি হওয়ার পর যে মান পরিবর্তন করা যায় না, যেমন string বা tuple।
Inheritance (ইনহেরিটেন্স) → সম্পর্কিত লেসন
একটি মেকানিজম যেখানে একটি ক্লাস (সাবক্লাস) অন্য একটি ক্লাসের (সুপারক্লাস) অ্যাট্রিবিউট/মেথড পুনর্ব্যবহার ও সম্প্রসারণ করে।
Integer (ইন্টিজার) → সম্পর্কিত লেসন
একটি পূর্ণসংখ্যা, পজিটিভ বা নেগেটিভ, কোনো দশমিক বিন্দু ছাড়া।
Iterable (ইটারেবল) → সম্পর্কিত লেসন
যে কোনো অবজেক্ট যা for লুপ দিয়ে ঘোরা যায় — লিস্ট, স্ট্রিং, ডিকশনারি, জেনারেটর, এবং আরও অনেক কিছু।
Iterator (ইটারেটর) → সম্পর্কিত লেসন
একটি অবজেক্ট যা প্রতিবার next() কল করলে সিকোয়েন্সের পরের মান তৈরি করে।

L

List (লিস্ট) → সম্পর্কিত লেসন
মানের একটি ক্রমিক, পরিবর্তনযোগ্য (mutable) সংগ্রহ।

M

Method (মেথড) → সম্পর্কিত লেসন
একটি ক্লাসের ভেতরে সংজ্ঞায়িত ফাংশন, ডট নোটেশন দিয়ে একটি অবজেক্টে কল করা হয়, যেমন my_list.append(3)।
Module (মডিউল) → সম্পর্কিত লেসন
একটি একক .py ফাইল যাতে Python কোড থাকে, যা import করে অন্য জায়গায় পুনর্ব্যবহার করা যায়।
Mutable (পরিবর্তনযোগ্য) → সম্পর্কিত লেসন
তৈরি হওয়ার পরও যে মান পরিবর্তন করা যায়, যেমন list বা dictionary।

P

Package (প্যাকেজ) → সম্পর্কিত লেসন
সম্পর্কিত মডিউলগুলোর একটি ফোল্ডার, সাধারণত একটি __init__.py ফাইল সহ।
Parameter (প্যারামিটার) → সম্পর্কিত লেসন
ফাংশনের সংজ্ঞায় থাকা নামযুক্ত placeholder, যা একটি argument গ্রহণ করবে, যেমন def greet(name)-এর name।
Polymorphism (পলিমরফিজম) → সম্পর্কিত লেসন
বিভিন্ন ক্লাসের একই মেথড কলে নিজ নিজ পদ্ধতিতে সাড়া দেওয়ার ক্ষমতা।

R

Recursion (রিকার্শন) → সম্পর্কিত লেসন
একটি ফাংশন যা নিজেকেই কল করে, সাধারণত ছোট ইনপুট দিয়ে, যতক্ষণ না একটি base case-এ পৌঁছায়।

S

Scope (স্কোপ) → সম্পর্কিত লেসন
কোডের যে অংশে একটি নির্দিষ্ট ভ্যারিয়েবলের নাম দৃশ্যমান ও ব্যবহারযোগ্য — লোকাল বনাম গ্লোবাল।
Set (সেট) → সম্পর্কিত লেসন
অনন্য (unique), সূচীবিহীন মানের একটি অক্রমিক সংগ্রহ।
String (স্ট্রিং) → সম্পর্কিত লেসন
টেক্সট বোঝাতে ব্যবহৃত ক্যারেক্টারের একটি সিকোয়েন্স, কোটেশনের ভেতরে লেখা হয়।

T

Tuple (টাপল) → সম্পর্কিত লেসন
মানের একটি ক্রমিক, অপরিবর্তনীয় (immutable) সংগ্রহ।

V

Variable (ভ্যারিয়েবল) → সম্পর্কিত লেসন
একটি নাম যা মেমরিতে সংরক্ষিত একটি মানের দিকে নির্দেশ করে।
