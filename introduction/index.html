মডিউল 01 — পরিচিতি ও সেটআপ

Python আসলে কী, কেন ইন্টারনেটের বিশাল একটা অংশ এর উপর দাঁড়িয়ে আছে, এবং বাস্তব কোড লেখার জন্য আপনার কম্পিউটার প্রস্তুত করা।

পূর্বশর্ত: কিছুই না — এখান থেকেই সবাই শুরু করে।

এই লেসন শেষে আপনি যা করতে পারবেন

  • Python আসলে কী এবং কেন এটি প্রথম ভাষা হিসেবে এত জনপ্রিয়, তা ব্যাখ্যা করতে পারা
  • Python 3 ইনস্টল করে টার্মিনাল থেকে সেটি কাজ করছে কিনা নিশ্চিত করা
  • VS Code ইনস্টল করে সেটিকে Git Bash-এর সাথে সংযুক্ত করা
  • নিজের প্রথম .py ফাইল লেখা, সংরক্ষণ করা এবং চালানো

ধারণা ও সিনট্যাক্স

Python একটি সাধারণ-উদ্দেশ্যের প্রোগ্রামিং ভাষা, যা প্রায় সাধারণ ইংরেজির মতোই সহজে পড়া যায় বলে পরিচিত। এটি তৈরি করেছেন Guido van Rossum, এবং প্রথম প্রকাশিত হয় ১৯৯১ সালে। আজ এটি চালাচ্ছে Instagram-এর ব্যাকএন্ড থেকে শুরু করে NASA-এর ডেটা পাইপলাইন, এমনকি ChatGPT-এর মতো টুলের পেছনের মেশিন-লার্নিং মডেল পর্যন্ত — সবকিছু।

একজন শিক্ষানবিসের জন্য Python গুরুত্বপূর্ণ একটি বাস্তব কারণে: "আমার একটা আইডিয়া আছে" থেকে "আমার কাজ করা কোড আছে" পর্যন্ত পৌঁছানোর দূরত্বটা Python-এ প্রায় অন্য যেকোনো ভাষার চেয়ে কম। মুখস্থ করার মতো যতিচিহ্ন কম, লেখার মতো বয়লারপ্লেট কোডও কম — তাই লেসনগুলো মনোযোগ দিতে পারে প্রোগ্রাম কীভাবে চিন্তা করে তার উপর, খুঁতখুঁতে কম্পাইলারকে খুশি করার উপর নয়।

পুরনো টিউটোরিয়ালে কখনো কখনো "Python 2"-এর কথা দেখতে পাবেন। Python 2-এর অফিসিয়াল সাপোর্ট শেষ হয়ে গেছে ১ জানুয়ারি, ২০২০ তারিখে, এবং এটি আর মেইনটেইন বা সুরক্ষিত নয়। এই সাইটের প্রতিটি লেসন আধুনিক Python 3-কে লক্ষ্য করে তৈরি — যদি কখনো print "text"-এর মতো প্যারেন্থিসিস ছাড়া কোড দেখেন, বুঝে নিন এটি Python 2, এবং মনে মনে সেটাকে print("text")-এ রূপান্তর করে নিতে পারেন।

Python বাস্তবে ব্যবহৃত হয়: ওয়েব ব্যাকএন্ডে (Django, Flask), ডেটা অ্যানালাইসিস ও ভিজ্যুয়ালাইজেশনে, অটোমেশন স্ক্রিপ্টে, ডেস্কটপ GUI অ্যাপে, এবং আধুনিক AI/ML গবেষণার সিংহভাগেই। এর মূল trade-off হলো কাঁচা এক্সিকিউশন গতি — Python প্রোগ্রাম সাধারণত C++ বা Rust-এর চেয়ে ধীরে চলে — কিন্তু বেশিরভাগ দৈনন্দিন সমস্যার জন্য, কোড লিখতে ও ডিবাগ করতে যে সময় বাঁচে, তা চালাতে যে মিলিসেকেন্ড খরচ হয় তার চেয়ে বেশি গুরুত্বপূর্ণ।

ভিজ্যুয়াল ব্যাখ্যা

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

ইন্টারপ্রিটার আপনার প্রথম লাইনটি কীভাবে চালায়, তা দেখুন

নিচের নিয়ন্ত্রণগুলো দিয়ে এই উদাহরণটি এক লাইন করে চালিয়ে দেখুন এবং ইন্টারপ্রিটারের মেমরি লাইভ পরিবর্তন হতে দেখুন।

আপনার .py ফাইল লাইন বাই লাইন পড়ে ও চালায়
শুধু বানান ভুল চেক করে
Python-কে JavaScript-এ রূপান্তর করে
ইন্টারপ্রিটারই সেই প্রোগ্রাম যা আসলে আপনার Python সোর্স কোড চালায়।

run app.py
python app.py
open app.py
app.py --start
python app.py (বা python3 app.py) ফাইলটি ইন্টারপ্রিটারের হাতে তুলে দেয়।

4. শিক্ষানবিসদের কাছে Python কেন এত জনপ্রিয়?

এটি রানটাইমে সবচেয়ে দ্রুত ভাষা
এর সিনট্যাক্স প্রায় সাধারণ ইংরেজির মতো, বয়লারপ্লেট খুব কম
এটি শুধু Windows-এ চলে
এটি ইনস্টল করার প্রয়োজন নেই
প্রোগ্রামিংয়ে নতুন মানুষদের জন্য পড়ার সহজতাই Python-এর সবচেয়ে বড় সুবিধা।

.py
.pt
.pyt
.python

সারাংশ

  • Python একটি শিক্ষানবিস-বান্ধব, সাধারণ-উদ্দেশ্যের ভাষা, যা ওয়েব, ডেটা, অটোমেশন এবং AI-তে ব্যবহৃত হয়।
  • সবসময় Python 3 ব্যবহার করুন — Python 2 আর সাপোর্টেড নয়।
  • একটি .py ফাইল আসলে সাধারণ টেক্সট; ইন্টারপ্রিটার এটি উপর থেকে নিচে পড়ে চালায়।
  • আপনি python filename.py দিয়ে টার্মিনাল থেকে ফাইল চালাতে পারেন।
