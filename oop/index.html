মডিউল 14 — অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং

বাস্তব জিনিসকে ক্লাস ও অবজেক্ট দিয়ে মডেল করা — বড় Python প্রোগ্রামের মূল ভিত্তি।

পূর্বশর্ত: মডিউল ১৩ — জেনারেটর

এই লেসন শেষে আপনি যা করতে পারবেন

  • একটি __init__ কনস্ট্রাক্টর ও instance মেথড সহ একটি ক্লাস সংজ্ঞায়িত করা
  • instance ভ্যারিয়েবল ও ক্লাস ভ্যারিয়েবলের পার্থক্য ব্যাখ্যা করা
  • সম্পর্কিত ক্লাসের মধ্যে আচরণ শেয়ার করতে inheritance ব্যবহার করা
  • @property ও __str__-এর মতো মৌলিক ম্যাজিক মেথড ব্যবহার করা

ধারণা ও সিনট্যাক্স

অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং (OOP) কোডকে অবজেক্ট-এর চারপাশে সাজায় — ডেটা (অ্যাট্রিবিউট) ও আচরণ (মেথড)-এর বান্ডেল, যা বাস্তব জিনিসের উপর ভিত্তি করে তৈরি। একটি ক্লাস হলো ব্লুপ্রিন্ট; একটি অবজেক্ট (বা instance) হলো সেই ব্লুপ্রিন্ট থেকে তৈরি একটি নির্দিষ্ট জিনিস। প্রতিটি Dog অবজেক্ট একই ব্লুপ্রিন্ট শেয়ার করে, কিন্তু প্রত্যেকের নিজের নাম, বয়স, ইত্যাদি আলাদা।

self শুধু একটি মেথডের কাছে বোঝায় "যে নির্দিষ্ট অবজেক্টের উপর আমাকে কল করা হয়েছে"। এটি সবসময় একটি instance মেথডের প্রথম প্যারামিটার, এবং Python এটি স্বয়ংক্রিয়ভাবে পাস করে — মেথড কল করার সময় আপনি নিজে কখনো এটি সরবরাহ করেন না।

        self.attribute = attribute
 
    def method(self):
        return self.attribute
 
obj = ClassName("value")

প্রতিটি অবজেক্ট name-এর নিজের একটি আলাদা কপি ধরে রাখে — এটাই 'instance' ভ্যারিয়েবলের মানে।

ক্লাস ভ্যারিয়েবল বনাম instance ভ্যারিয়েবল মধ্যম

ক্লাস ভ্যারিয়েবল বনাম instance ভ্যারিয়েবল
class Dog:
    species = "Canis familiaris"  # ক্লাস ভ্যারিয়েবল — সব কুকুরের জন্য শেয়ার করা
 
    def __init__(self, name):
        self.name = name  # instance ভ্যারিয়েবল — প্রতিটি কুকুরের নিজস্ব
 
rex = Dog("Rex")
fido = Dog("Fido")
print(rex.species, fido.species)
print(rex.name, fido.name)
আউটপুটCanis familiaris Canis familiaris Rex Fido

species ক্লাসে একবার সংজ্ঞায়িত হয়ে প্রতিটি instance-এ শেয়ার হয়; name __init__-এর ভেতরে প্রতি-অবজেক্ট আলাদা করে সেট হয়।

Inheritance
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return f"{self.name} makes a sound."
 
class Dog(Animal):
    def speak(self):
        return f"{self.name} barks."
 
rex = Dog("Rex")
print(rex.speak())
আউটপুটRex barks.

class Dog(Animal) মানে Dog Animal থেকে সবকিছু ইনহেরিট করে, তারপর speak()-কে তার নিজের ভার্সন দিয়ে ওভাররাইড করে — এটাকে বলা হয় method overriding।

@property ও __str__ চ্যালেঞ্জ

@property ও __str__
class Circle:
    def __init__(self, radius):
        self.radius = radius
 
    @property
    def area(self):
        return 3.14159 * self.radius ** 2
 
    def __str__(self):
        return f"Circle(radius={self.radius})"
 
c = Circle(4)
print(c)
print(c.area)
আউটপুটCircle(radius=4) 50.26544

@property আপনাকে c.area-কে একটি সাধারণ অ্যাট্রিবিউটের মতো কল করতে দেয়, যদিও এটা হিসাব করা হয়। __str__ নিয়ন্ত্রণ করে print() একটি অবজেক্টের জন্য কী দেখাবে।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

একটি অবজেক্ট তৈরি হওয়া ও ব্যবহৃত হওয়া দেখুন

একটি balance, একটি deposit(amount) মেথড, এবং একটি withdraw(amount) মেথড সহ BankAccount ক্লাস মডেল করুন যা অ্যাকাউন্ট ওভারড্র করতে দেয় না।

  • withdraw() নেগেটিভ balance-এর অনুমতি না দিয়ে একটি এরর মেসেজ প্রিন্ট করবে
💡 ইঙ্গিত প্রয়োজন?

withdraw()-এর ভেতরে বিয়োগ করার আগে `if amount > self.balance:` চেক করুন।

🔍 একটি নমুনা সমাধান দেখুন
Python
class BankAccount:
    def __init__(self):
        self.balance = 0
 
    def deposit(self, amount):
        self.balance += amount
 
    def withdraw(self, amount):
        if amount > self.balance:
            print("Insufficient funds")
        else:
            self.balance -= amount
 
acc = BankAccount()
acc.deposit(100)
acc.withdraw(30)
print(acc.balance)

3. class Dog(Animal) মানে কী?

Dog এবং Animal-এর কোনো সম্পর্ক নেই
Dog Animal থেকে অ্যাট্রিবিউট ও মেথড ইনহেরিট করে
Animal Dog থেকে ইনহেরিট করে
এটি অবৈধ সিনট্যাক্স
Dog(Animal) মানে Dog একটি সাবক্লাস যা Animal সুপারক্লাস থেকে ইনহেরিট করে।

4. __init__ কী করে?

একটি অবজেক্ট মুছে দেয়
একটি অবজেক্ট তৈরি হলে স্বয়ংক্রিয়ভাবে চলে, এটি প্রস্তুত করার জন্য
একটি অবজেক্ট প্রিন্ট করে
দুটো অবজেক্ট তুলনা করে
__init__ হলো কনস্ট্রাক্টর, যা একটি নতুন অবজেক্ট তৈরি হলে স্বয়ংক্রিয়ভাবে কল হয়।

5. @property কী করার সুযোগ দেয়?

একটি মেথডকে সাধারণ অ্যাট্রিবিউটের মতো কল করা
একটি ক্লাস মুছে দেওয়া
__init__ লেখা এড়িয়ে যাওয়া
একটি গ্লোবাল ভ্যারিয়েবল তৈরি করা
@property একটি মেথডকে প্যারেন্থিসিস ছাড়াই, একটি অ্যাট্রিবিউটের মতো অ্যাক্সেস করতে দেয়।

সারাংশ

  • একটি ক্লাস একটি ব্লুপ্রিন্ট; একটি অবজেক্ট সেটা থেকে তৈরি হওয়া একটি instance।
  • self একটি instance মেথডের ভেতরে বর্তমান অবজেক্টকে নির্দেশ করে।
  • Instance ভ্যারিয়েবল প্রতি-অবজেক্ট; ক্লাস ভ্যারিয়েবল সব instance শেয়ার করে।
  • Inheritance (class Dog(Animal)) একটি সাবক্লাসকে একটি সুপারক্লাসের আচরণ পুনর্ব্যবহার ও ওভাররাইড করতে দেয়।
