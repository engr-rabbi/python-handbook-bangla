মডিউল 17 — OS ও সিস্টেম মডিউল

Python-এর ভেতর থেকে ফোল্ডার, পাথ, ও ফাইলের সাথে কাজ করা।

পূর্বশর্ত: মডিউল ১৬ — ফাইল I/O

এই লেসন শেষে আপনি যা করতে পারবেন

  • os ও pathlib দিয়ে ফাইলসিস্টেম দেখা ও পরীক্ষা করা
  • ফাইল ও ফোল্ডার তৈরি, নাম বদল, ও বাদ দেওয়া
  • shutil দিয়ে ফাইল কপি ও সরানো

ধারণা ও সিনট্যাক্স

os ও pathlib মডিউল একটি Python প্রোগ্রামকে ফাইলসিস্টেমের সাথে সরাসরি কাজ করতে দেয় — ফোল্ডার তালিকা করা, Windows এবং Mac/Linux দুটোতেই কাজ করে এমন পাথ তৈরি করা, এবং ডিরেক্টরি তৈরি বা বাদ দেওয়া। shutil কপি করা ও সরানোর মতো উচ্চ-স্তরের ফাইল অপারেশন যুক্त করে।

pathlib হলো আধুনিক, প্রস্তাবিত পদ্ধতি: এটি একটি ফাইল পাথকে একটি অবজেক্ট হিসেবে (শুধু একটি স্ট্রিং না) প্রকাশ করে, যা বিভিন্ন অপারেটিং সিস্টেমের মধ্যে পাথ তৈরিকে অনেক কম ভুল-প্রবণ করে দেয়।

সিনট্যাক্স
from pathlib import Path
p = Path("data") / "scores.csv"
p.exists()
p.parent
os.listdir(".")

উদাহরণ

pathlib দিয়ে একটি পাথ তৈরি করা খুব সহজ

pathlib দিয়ে একটি পাথ তৈরি করা
from pathlib import Path
data_file = Path("data") / "scores.csv"
print(data_file)
আউটপুটdata/scores.csv

/ অপারেটর বর্তমান অপারেটিং সিস্টেমের জন্য পাথের টুকরোগুলো সঠিকভাবে জোড়া দেয় — ম্যানুয়ালি স্ল্যাশ বা ব্যাকস্ল্যাশ সামলানোর প্রয়োজন নেই।

অস্তিত্ব যাচাই ও একটি ফোল্ডার তালিকা করা সহজ

অস্তিত্ব যাচাই ও একটি ফোল্ডার তালিকা করা
import os
from pathlib import Path
print(Path("data").exists())
for name in os.listdir("."):
    print(name)
আউটপুটTrue (বর্তমান ডিরেক্টরির ফাইল/ফোল্ডারগুলো)

exists() কোনো পাথ আসলে আছে কিনা চেক করে; os.listdir(path) একটি ফোল্ডারের ভেতরের সবকিছু তালিকা করে।

ফোল্ডার তৈরি করা মধ্যম

ফোল্ডার তৈরি করা
import os
os.makedirs("reports/2026", exist_ok=True)
আউটপুট(reports/2026 তৈরি করে, প্রয়োজনে reports সহ — আগে থাকলে এরর দেয় না)

makedirs() পাথের মধ্যে অনুপস্থিত প্রতিটি ফোল্ডার তৈরি করে; exist_ok=True এটি আগে থেকে থাকলে এরর দেওয়া বন্ধ করে দেয়।

ফাইল কপি করা ও সরানো বাস্তব উদাহরণ

ফাইল কপি করা ও সরানো
import shutil
shutil.copy("notes.txt", "backup_notes.txt")
shutil.move("backup_notes.txt", "archive/backup_notes.txt")
আউটপুট(কপি করে তারপর সরায় — কোনো কনসোল আউটপুট নেই)

shutil.copy() একটি ফাইল কপি করে; shutil.move() এটি সরায় (এবং নাম বদলাতেও ব্যবহার করা যায়)।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

os ফাংশন দিয়ে একটি ফাইল বা ফোল্ডার বাদ দেওয়া স্থায়ী — এতে কোনো recycle bin/trash জড়িত থাকে না।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে ক্র্যাশ নয়, কিন্তু ভুল হলে ডেটা হারিয়ে যায়
import os
os.remove("important_report.txt")  # কোনো নিশ্চিতকরণ ছাড়াই তাৎক্ষণিক চলে যায়
✓ সঠিক পদ্ধতি
সংশোধিত
import os
if os.path.exists("important_report.txt"):
    confirm = input("Really delete important_report.txt? (yes/no) ")
    if confirm == "yes":
        os.remove("important_report.txt")
✓ ভালো অভ্যাস
  • + বা স্ট্রিং ফরম্যাটিং দিয়ে ম্যানুয়ালি পাথ স্ট্রিং বানানোর চেয়ে pathlib.Path বেশি পছন্দ করুন।
  • স্থায়ীভাবে কিছু বাদ দেওয়া বা ওভাররাইট করার আগে সবসময় exists() চেক করুন।
  • একটি ফোল্ডার আগে থেকেই থাকতে পারে এমন পরিস্থিতিতে এরর এড়াতে os.makedirs()-এ exist_ok=True ব্যবহার করুন।

🏆 চ্যালেঞ্জ

একটি স্ক্রিপ্ট লিখুন যা না থাকলে 'archive' নামে একটি ফোল্ডার তৈরি করে, তারপর বর্তমান ডিরেক্টরিতে '.txt'-তে শেষ হওয়া প্রতিটি ফাইল তালিকা করে।

  • exist_ok=True সহ os.makedirs ব্যবহার করুন
  • os.listdir() ব্যবহার করে প্রতিটি নাম .endswith('.txt') দিয়ে চেক করুন
  • প্রতিটি মিলে যাওয়া ফাইলের নাম প্রিন্ট করুন
💡 ইঙ্গিত প্রয়োজন?

"report.txt".endswith(".txt") হয় True।

🔍 একটি নমুনা সমাধান দেখুন
Python
import os
os.makedirs("archive", exist_ok=True)
for name in os.listdir("."):
    if name.endswith(".txt"):
        print(name)

কুইজ

প্রতিটি প্রশ্নের উত্তর দিন, তারপর জমা দিয়ে নিজের স্কোর ও ব্যাখ্যা দেখুন।

1. দুটো Path অবজেক্টের মাঝে / অপারেটর কী করে?

সংখ্যা ভাগ করে
বর্তমান OS-এর জন্য পাথ সেগমেন্ট সঠিকভাবে জোড়া দেয়
একটি ফাইল বাদ দেয়
কিছুই না, এটি অবৈধ
pathlib বিশেষভাবে ফাইল পাথ তৈরির জন্য / ওভারলোড করে।

2. os.makedirs()-এ exist_ok=True কী করে?

ফোল্ডারটি আগে থেকে থাকলে বাদ দেয়
ফোল্ডারটি আগে থেকে থাকলে এরর প্রতিরোধ করে
ফোল্ডারটি read-only করে দেয়
কোনো প্রভাব নেই
এটা না থাকলে, টার্গেট আগে থেকে থাকলে makedirs() এরর দেয়।

3. কোন মডিউল copy ও move-এর মতো উচ্চ-স্তরের ফাইল অপারেশন দেয়?

os
sys
shutil
pathlib
shutil (shell utilities) copy(), move(), ও এই ধরনের উচ্চ-স্তরের অপারেশন দেয়।

সারাংশ

  • pathlib.Path ফাইল পাথকে অবজেক্ট হিসেবে প্রকাশ করে এবং OS-এর পার্থক্য স্বয়ংক্রিয়ভাবে সামলায়।
  • os.listdir(), os.makedirs(), এবং os.remove() সরাসরি ফোল্ডার ও ফাইল ম্যানেজ করে।
  • shutil.copy() ও shutil.move() উচ্চ-স্তরের ফাইল অপারেশন সামলায়।
  • বাদ দেওয়ার আগে সবসময় দুইবার চেক করুন — ফাইলসিস্টেম অপারেশন সাধারণত স্থায়ী।
