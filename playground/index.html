লাইভ পাইথন প্লেগ্রাউন্ড

আপনার ব্রাউজারেই সরাসরি চলছে একটি সম্পূর্ণ, বাস্তব Python ইন্টারপ্রিটার — Pyodide (WebAssembly) দিয়ে। কিছুই কোনো সার্ভারে পাঠানো হয় না। প্রথমবার চালালে Python ইঞ্জিন ডাউনলোড হয়, তাই শুরু হতে কয়েক সেকেন্ড লাগে; তারপর প্রতিটি রান তাৎক্ষণিক।

আউটপুট এখানে দেখা যাবে।
✓ এখানে যা কাজ করে

বিশুদ্ধ Python — ভ্যারিয়েবল, ফাংশন, ক্লাস, লুপ, স্ট্রিং/লিস্ট/ডিকশনারি অপারেশন, গণিত, এবং স্ট্যান্ডার্ড লাইব্রেরির প্রায় সবকিছু যেগুলোর জন্য বাস্তব ফাইল বা নেটওয়ার্ক লাগে না, যেমন random, json, math, এবং datetime।

✗ ব্রাউজারে যা সীমিত

বাস্তব ফাইলসিস্টেম অ্যাক্সেস, Tkinter-এর মতো GUI টুলকিট, এবং লাইভ নেটওয়ার্ক রিকোয়েস্ট এই ব্রাউজার-ভিত্তিক প্লেগ্রাউন্ডে পাওয়া যায় না, কারণ এটি পেজের ভেতরে sandbox করা অবস্থায় চলে। Python ইনস্টল করার পর (মডিউল ০১) সেই উদাহরণগুলো নিজের কম্পিউটারে চালিয়ে দেখুন।
