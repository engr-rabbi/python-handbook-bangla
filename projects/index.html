পূর্বাভাস: সংখ্যা অনুমান খেলা — পরিকল্পনা
# উদ্দেশ্য: কম্পিউটার 1-100-এর মধ্যে একটি গোপন সংখ্যা বাছে; খেলোয়াড় প্রতিটি
# অনুমানের পর "higher/lower" ইঙ্গিত পেয়ে সঠিক না হওয়া পর্যন্ত অনুমান করতে থাকে।
#

আউটপুট(পরিকল্পনার নোট — এখনো কোনো কোড চলেনি)

কোড লেখার আগে সাধারণ ইংরেজি/বাংলায় প্ল্যান লেখা এমন একটি অভ্যাস যা গোড়া থেকেই তৈরি করার মতো — এটি একটি অস্পষ্ট আইডিয়াকে একটি নির্দিষ্ট চেকলিস্টে বদলে দেয়।

পূর্বাভাস: সংখ্যা অনুমান খেলা — সম্পূর্ণ কোড বাস্তব উদাহরণ

পূর্বাভাস: সংখ্যা অনুমান খেলা — সম্পূর্ণ কোড
import random
 
secret = random.randint(1, 100)
attempts = 0
 
while True:
    guess = int(input("Guess a number (1-100): "))
    attempts += 1
    if guess < secret:
        print("Higher!")
    elif guess > secret:
        print("Lower!")
    else:
        print(f"Correct! It took you {attempts} attempts.")
        break
আউটপুটGuess a number (1-100): 50 Higher! Guess a number (1-100): 75 Lower! Guess a number (1-100): 63 Correct! It took you 3 attempts.

এতে একটি while লুপ, if/elif/else, input()/int(), এবং random মডিউল একসাথে ব্যবহৃত হয়েছে — এই কোর্সে আগেই শেখা প্রতিটি বিষয়।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

অনুশীলনী 1 — আউটপুট অনুমান করুন

উপরের সংখ্যা অনুমান খেলার কোডে, খেলোয়াড়ের প্রথম অনুমানটিই যদি ঠিক গোপন সংখ্যা হয়, তাহলে কী ঘটে?

এটি 'Correct! It took you 1 attempts.' প্রিন্ট করে এবং break দিয়ে লুপটি তাৎক্ষণিক শেষ হয়ে যায়।

🏆 চ্যালেঞ্জ

উপরের সম্প্রসারণ আইডিয়া থেকে একটি বাছুন (চেষ্টার সীমা, হাই-স্কোর লিস্ট, বা ফাইল সংরক্ষণ) এবং মূল খেলার উপর এটি বাস্তবায়ন করুন।

  • কার্যকরী মূল খেলা থেকে শুরু করুন
  • ঠিক একটি নতুন ফিচার যোগ করুন
  • আপনার পরিবর্তনের পরেও মূল খেলাটি ঠিকমতো কাজ করছে কিনা পরীক্ষা করুন
💡 ইঙ্গিত প্রয়োজন?

একটি চেষ্টার সীমার জন্য শুধু লুপের ভেতরে if attempts >= 7: break চেক লাগবে।

🔍 একটি নমুনা সমাধান দেখুন
Python
import random
 
secret = random.randint(1, 100)
attempts = 0
max_attempts = 7
 
while attempts < max_attempts:
    guess = int(input("Guess a number (1-100): "))
    attempts += 1
    if guess < secret:
        print("Higher!")
    elif guess > secret:
        print("Lower!")
    else:
        print(f"Correct! It took you {attempts} attempts.")
        break
else:
    print(f"Out of attempts! The number was {secret}.")

2. একটি প্রজেক্টের সবচেয়ে ছোট কার্যকরী ভার্সন প্রথমে তৈরি করা কেন গুরুত্বপূর্ণ?

Python-এর জন্য এটা বাধ্যতামূলক
এতে বাগ আলাদা করে খুঁজে বের করা একসাথে সব বানানোর চেয়ে অনেক সহজ হয়
টাইপ করতে বেশি দ্রুত হয়
আসলে কোনো লাভ নেই
ধাপে ধাপে ডেভেলপমেন্ট মানে প্রতিটি নতুন বাগ সম্ভবত আপনার শেষে যোগ করা একমাত্র জিনিসের কারণেই হয়েছে।

সারাংশ

  • কোনো কোড লেখার আগে প্রতিটি প্রজেক্ট একটি ছোট লিখিত পরিকল্পনা থেকে উপকৃত হয়।
  • প্রথমে সবচেয়ে সহজ কার্যকরী ভার্সন তৈরি করুন, পরীক্ষা করুন, তারপর একটা একটা করে ফিচার যোগ করুন।
  • সংখ্যা অনুমান খেলাটি আগের মডিউলের লুপ, কন্ডিশনাল, ও ইনপুট হ্যান্ডলিং একসাথে ব্যবহার করে।
  • সম্পূর্ণ প্রজেক্ট ড্যাশবোর্ডে শুরু, মধ্যম, ও অ্যাডভান্সড প্রজেক্ট, এবং একটি ক্যাপস্টোন আছে।
