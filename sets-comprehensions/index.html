মডিউল 09 — সেট ও কম্প্রিহেনশন

অনন্য সংগ্রহ, এবং লিস্ট ও ডিকশনারি তৈরির একটি দ্রুততর, বেশি Pythonic পদ্ধতি।

পূর্বশর্ত: মডিউল ০৮ — ডিকশনারি

এই লেসন শেষে আপনি যা করতে পারবেন

  • সেট তৈরি করা এবং union, intersection, ও difference ব্যবহার করা
  • append-লুপকে list comprehension-এ পুনর্লিখন করা
  • if / if-else দিয়ে একটি comprehension-এ শর্ত যোগ করা
  • dictionary ও set comprehension লেখা

ধারণা ও সিনট্যাক্স

একটি সেট হলো অনন্য মানের একটি অক্রমিক সংগ্রহ — ডুপ্লিকেট স্বয়ংক্রিয়ভাবে বাদ পড়ে যায়। যখন ক্রমের চেয়ে "এটা কি ইতিমধ্যে আছে?" বা "এই দুই গ্রুপে কী কমন আছে?" প্রশ্নটাই বেশি গুরুত্বপূর্ণ, তখন সেট সঠিক টুল।

একটি কম্প্রিহেনশন হলো একটি বিদ্যমান সংগ্রহের প্রতিটি আইটেম রূপান্তর করে এক লাইনেই একটি নতুন লিস্ট, ডিকশনারি বা সেট তৈরির একটি সংক্ষিপ্ত পদ্ধতি, append() দিয়ে একটি ম্যানুয়াল লুপ লেখার বদলে।

সিনট্যাক্স
unique = {1, 2, 3}
squares = [x * x for x in numbers]
evens = [x for x in numbers if x % 2 == 0]
square_map = {x: x * x for x in numbers}

উদাহরণ

একটি সেট তৈরি করা খুব সহজ

একটি সেট তৈরি করা
tags = {"python", "code", "python", "learn"}
print(tags)
আউটপুট{'python', 'code', 'learn'}

ডুপ্লিকেট 'python' স্বয়ংক্রিয়ভাবে বাদ পড়ে যায় — সেটে কখনো পুনরাবৃত্ত মান থাকে না। (প্রিন্ট করা আউটপুটের ক্রম ভিন্ন হতে পারে।)

সেট অপারেশন সহজ

সেট অপারেশন
backend = {"python", "sql", "docker"}
frontend = {"javascript", "css", "python"}
print(backend & frontend)
print(backend | frontend)
print(backend - frontend)
আউটপুট{'python'} {'python', 'sql', 'docker', 'javascript', 'css'} {'sql', 'docker'}

& হলো intersection (দুটোতেই আছে), | হলো union (যেকোনো একটিতে আছে), - হলো difference (প্রথমটিতে আছে কিন্তু দ্বিতীয়টিতে নেই)।

List comprehension মধ্যম

List comprehension
numbers = [1, 2, 3, 4, 5]
squares = [x * x for x in numbers]
print(squares)
আউটপুট[1, 4, 9, 16, 25]

এটি ৩ লাইনের একটি append লুপকে একটি এক্সপ্রেসিভ লাইনে বদলে দেয়: 'numbers-এর প্রতিটি x-এর জন্য x*x দাও'।

একটি শর্ত সহ কম্প্রিহেনশন বাস্তব উদাহরণ

একটি শর্ত সহ কম্প্রিহেনশন
numbers = range(1, 11)
evens = [n for n in numbers if n % 2 == 0]
labels = ["even" if n % 2 == 0 else "odd" for n in numbers]
print(evens)
print(labels)
আউটপুট[2, 4, 6, 8, 10] ['odd', 'even', 'odd', 'even', 'odd', 'even', 'odd', 'even', 'odd', 'even']

শেষে একটি if আইটেম ফিল্টার করে; এক্সপ্রেশনের আগে if/else বরং প্রতিটি আইটেমকে একটি শর্তের ভিত্তিতে ভিন্নভাবে রূপান্তর করে।

Dictionary comprehension চ্যালেঞ্জ

Dictionary comprehension
words = ["cat", "elephant", "dog"]
lengths = {word: len(word) for word in words}
print(lengths)
আউটপুট{'cat': 3, 'elephant': 8, 'dog': 3}

একই {key: value for ...} প্যাটার্ন লিস্টের বদলে একটি ডিকশনারি তৈরি করে।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

একটি কম্প্রিহেনশনে খুব বেশি লজিক ভরে দেওয়া readability নষ্ট করে — এক লাইনে ফিট না হলে, একটি সাধারণ লুপই ভালো।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে কোনো এরর নয়, কিন্তু পড়া ও ডিবাগ করা কঠিন
result = [y for y in [x*2 for x in range(20) if x % 3 == 0] if y > 10 if y < 30]
✓ সঠিক পদ্ধতি
সংশোধিত
doubled_multiples_of_3 = [x * 2 for x in range(20) if x % 3 == 0]
result = [y for y in doubled_multiples_of_3 if 10 < y < 30]
✓ ভালো অভ্যাস
  • লুপের বডি একটি সাধারণ এক্সপ্রেশন হলে একটি কম্প্রিহেনশন বেছে নিন।
  • একটি কম্প্রিহেনশনে একের বেশি শর্ত বা নেস্টেড লুপ লাগলে সাধারণ for লুপে ফিরে যান।
  • uniqueness নিশ্চিত করতে বা প্রায়ই মেম্বারশিপ চেক করতে হলে লিস্টের বদলে সেট ব্যবহার করুন — সেটের lookup অনেক বেশি দ্রুত।

অনুশীলনী ও চ্যালেঞ্জ

অনুশীলনী 1 — আউটপুট অনুমান করুন

এই কোডটি দেওয়া আছে
nums = [1, 2, 3, 4]
result = [n for n in nums if n > 2]
print(result)

💡 if ক্লজ এমন আইটেম বাদ দেয় যা শর্ত পূরণ করে না।

[3, 4]

🏆 চ্যালেঞ্জ

শব্দের একটি লিস্ট দেওয়া থাকলে, একটি dictionary comprehension ব্যবহার করে প্রতিটি অনন্য শব্দকে True (যদি এটি একটি স্বরবর্ণে শুরু হয়) বা False দিয়ে ম্যাপ করা একটি ডিকশনারি তৈরি করুন।

  • একটি dictionary comprehension ব্যবহার করুন
  • word[0].lower() in "aeiou" দিয়ে প্রথম অক্ষর চেক করুন
  • কমপক্ষে ৪টি শব্দ দিয়ে পরীক্ষা করুন
💡 ইঙ্গিত প্রয়োজন?

{word: word[0].lower() in "aeiou" for word in words}

🔍 একটি নমুনা সমাধান দেখুন
Python
words = ["apple", "banana", "orange", "kiwi"]
starts_with_vowel = {word: word[0].lower() in "aeiou" for word in words}
print(starts_with_vowel)

4. কোন সিনট্যাক্স একটি dictionary comprehension তৈরি করে?

[k: v for ...]

(k: v for ...)
dict[k:v for ...]
কার্লি ব্রেসের ভেতরে key:value জোড়া একটি dict comprehension সংজ্ঞায়িত করে।

সারাংশ

  • সেট অনন্য, অক্রমিক মান সংরক্ষণ করে এবং &, |, ও - অপারেশন সাপোর্ট করে।
  • List comprehension একটি বিদ্যমান iterable থেকে এক লাইনে একটি নতুন লিস্ট তৈরি করে।
  • শেষে একটি if ফিল্টার করে; এক্সপ্রেশনের আগে if/else শর্তসাপেক্ষে রূপান্তর করে।
  • একই প্যাটার্ন {} দিয়ে dictionary ও set comprehension-এও চলে।
