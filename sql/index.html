মডিউল 20 — Python + SQL

সরাসরি Python থেকে SQLite দিয়ে ডেটা স্থায়ীভাবে সংরক্ষণ ও query করা।

পূর্বশর্ত: মডিউল ১৯ — Python প্রজেক্ট

এই লেসন শেষে আপনি যা করতে পারবেন

  • Python থেকে একটি SQLite ডেটাবেসের সাথে সংযুক্ত হওয়া ও একটি টেবিল তৈরি করা
  • SQL দিয়ে রেকর্ড ইনসার্ট, সিলেক্ট, আপডেট, ও ডিলিট করা
  • একটি সহজ CRUD (Create, Read, Update, Delete) ওয়ার্কফ্লো তৈরি করা

ধারণা ও সিনট্যাক্স

ছোট পরিমাণ ডেটার জন্য ফাইল ঠিকই আছে, কিন্তু একবার আপনার খোঁজা, ফিল্টার করা, সাজানো, বা নির্ভরযোগ্যভাবে রেকর্ড আপডেট করার প্রয়োজন হলে, একটি ডেটাবেসই সঠিক টুল। SQL (Structured Query Language) হলো relational ডেটাবেসের সাথে কথা বলতে ব্যবহৃত ভাষা। SQLite হলো একটি লাইটওয়েট, ফাইল-ভিত্তিক ডেটাবেস ইঞ্জিন যা Python-এর স্ট্যান্ডার্ড লাইব্রেরিতে sqlite3 মডিউল দিয়ে বিল্ট-ইন রয়েছে — কোনো আলাদা সার্ভার লাগে না, যা এটিকে শেখার জন্য এবং ছোট অ্যাপ্লিকেশনের জন্য আদর্শ করে তোলে।

সিনট্যাক্স
import sqlite3
conn = sqlite3.connect("app.db")
cursor = conn.cursor()
cursor.execute("SELECT * FROM students WHERE grade > ?", (80,))
conn.commit()
conn.close()

উদাহরণ

সংযুক্ত হওয়া ও একটি টেবিল তৈরি করা খুব সহজ

সংযুক্ত হওয়া ও একটি টেবিল তৈরি করা
import sqlite3
 
conn = sqlite3.connect("school.db")
cursor = conn.cursor()
cursor.execute("""
    CREATE TABLE IF NOT EXISTS students (
        id INTEGER PRIMARY KEY,
        name TEXT,
        grade INTEGER
    )
""")
conn.commit()
conn.close()
আউটপুট(একটি খালি students টেবিল সহ school.db তৈরি করে — কোনো কনসোল আউটপুট নেই)

connect() ডেটাবেস ফাইলটি খোলে (বা তৈরি করে)। IF NOT EXISTS টেবিল আগে থেকে থাকলে এরর প্রতিরোধ করে। commit() পরিবর্তনটি ডিস্কে সংরক্ষণ করে।

নিরাপদে রেকর্ড ইনসার্ট করা সহজ

নিরাপদে রেকর্ড ইনসার্ট করা
import sqlite3
 
conn = sqlite3.connect("school.db")
cursor = conn.cursor()
cursor.execute("INSERT INTO students (name, grade) VALUES (?, ?)", ("Ada", 92))
conn.commit()
conn.close()
আউটপুট(students টেবিলে একটি row যোগ করে)

? placeholder-গুলো টাপল থেকে নিরাপদে পূরণ হয় — সবসময় এভাবেই করুন, + দিয়ে SQL স্ট্রিং বানানোর বদলে, যা SQL injection বাগের দরজা খুলে দেয়।

WHERE ও ORDER BY দিয়ে সিলেক্ট করা মধ্যম

WHERE ও ORDER BY দিয়ে সিলেক্ট করা
import sqlite3
 
conn = sqlite3.connect("school.db")
cursor = conn.cursor()
cursor.execute("SELECT name, grade FROM students WHERE grade > ? ORDER BY grade DESC", (80,))
for row in cursor.fetchall():
    print(row)
conn.close()
আউটপুট('Ada', 92)

WHERE row ফিল্টার করে; ORDER BY grade DESC ফলাফল সর্বোচ্চ থেকে সর্বনিম্ন grade অনুযায়ী সাজায়। fetchall() প্রতিটি মিলে যাওয়া row টাপলের একটি লিস্ট হিসেবে ফিরিয়ে দেয়।

আপডেট ও ডিলিট করা বাস্তব উদাহরণ

আপডেট ও ডিলিট করা
import sqlite3
 
conn = sqlite3.connect("school.db")
cursor = conn.cursor()
cursor.execute("UPDATE students SET grade = ? WHERE name = ?", (95, "Ada"))
cursor.execute("DELETE FROM students WHERE grade < ?", (50,))
conn.commit()
conn.close()
আউটপুট(Ada-এর grade আপডেট করে, 50-এর কম grade থাকা কোনো শিক্ষার্থী থাকলে বাদ দেয় — কোনো কনসোল আউটপুট নেই)

UPDATE WHERE-এ মিলে যাওয়া বিদ্যমান row বদলায়; DELETE WHERE-এ মিলে যাওয়া row বাদ দেয়। দুটোতেই আসলে সংরক্ষণ করতে commit() লাগবে।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

সরাসরি ব্যবহারকারীর ইনপুট বসিয়ে SQL স্ট্রিং বানানো SQL injection নামে একটি গুরুত্বপূর্ণ সিকিউরিটি ঝুঁকি তৈরি করে।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে কোনো Python এরর নয়, কিন্তু একটি আসল সিকিউরিটি ঝুঁকি
name = input("Name: ")
cursor.execute(f"SELECT * FROM students WHERE name = '{name}'")

conn.commit() ভুলে গেলে INSERT/UPDATE/DELETE পরিবর্তনগুলো সংযোগ বন্ধ হওয়ার সাথে সাথেই হারিয়ে যায়।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে ক্র্যাশ নয়, কিন্তু ডেটা নিঃশব্দে কখনো সংরক্ষিত হয় না
cursor.execute("INSERT INTO students (name, grade) VALUES (?, ?)", ("Sam", 88))

সংশোধিত

✓ ভালো অভ্যাস
  • একটি query-তে মানের জন্য সবসময় ? placeholder ব্যবহার করুন — কখনো স্ট্রিং ফরম্যাটিং দিয়ে SQL বানাবেন না।
  • কোনো INSERT, UPDATE, বা DELETE-এর পর conn.commit() কল করুন।
  • ডেটাবেসের কাজ শেষ হলে সংযোগ বন্ধ করে দিন (বা একটি with ব্লক ব্যবহার করুন)।
  • CREATE TABLE IF NOT EXISTS ব্যবহার করুন যাতে সেটআপ কোড একের বেশি বার নিরাপদে চলতে পারে।

🏆 চ্যালেঞ্জ

'books' টেবিলের (id, title, author) জন্য একটি ছোট CRUD স্ক্রিপ্ট তৈরি করুন যা টেবিল তৈরি করে, দুটি বই ইনসার্ট করে, তারপর title অনুযায়ী সাজিয়ে প্রতিটি বই সিলেক্ট করে প্রিন্ট করে।

  • CREATE TABLE IF NOT EXISTS ব্যবহার করুন
  • ? placeholder দিয়ে কমপক্ষে ২টি row ইনসার্ট করুন
  • ORDER BY title দিয়ে SELECT করুন, এবং প্রতিটি row প্রিন্ট করুন
💡 ইঙ্গিত প্রয়োজন?

cursor.execute("SELECT * FROM books ORDER BY title")

🔍 একটি নমুনা সমাধান দেখুন
Python
import sqlite3
 
conn = sqlite3.connect("library.db")
cursor = conn.cursor()
cursor.execute("CREATE TABLE IF NOT EXISTS books (id INTEGER PRIMARY KEY, title TEXT, author TEXT)")
cursor.execute("INSERT INTO books (title, author) VALUES (?, ?)", ("Dune", "Herbert"))
cursor.execute("INSERT INTO books (title, author) VALUES (?, ?)", ("Emma", "Austen"))
conn.commit()
cursor.execute("SELECT * FROM books ORDER BY title")
for row in cursor.fetchall():
    print(row)
conn.close()

সারাংশ

  • sqlite3 কোনো আলাদা সার্ভার ছাড়াই Python-কে একটি লাইটওয়েট, ফাইল-ভিত্তিক SQL ডেটাবেসের সাথে সংযুক্त করে।
  • মানের জন্য ? placeholder ব্যবহার করুন — সরাসরি ব্যবহারকারীর ইনপুট দিয়ে SQL স্ট্রিং বানাবেন না।
  • commit() INSERT/UPDATE/DELETE পরিবর্তন সংরক্ষণ করে; এটা না হলে হারিয়ে যেতে পারে।
  • WHERE row ফিল্টার করে এবং ORDER BY সেগুলো সাজায় — প্রতিটি উপকারী query-এর ভিত্তি।
