মডিউল 18 — Tkinter দিয়ে GUI প্রোগ্রামিং

আপনার প্রথম উইন্ডো-যুক্ত, ক্লিকযোগ্য ডেস্কটপ অ্যাপ্লিকেশন তৈরি করা।

পূর্বশর্ত: মডিউল ১৭ — OS ও সিস্টেম মডিউল

এই লেসন শেষে আপনি যা করতে পারবেন

  • একটি উইন্ডো তৈরি করা এবং লেবেল, বাটন, ও এন্ট্রি ফিল্ড যোগ করা
  • একটি callback ফাংশন দিয়ে একটি বাটন ক্লিকে সাড়া দেওয়া
  • event-driven প্রোগ্রামিং ব্যাখ্যা করা

ধারণা ও সিনট্যাক্স

এখন পর্যন্ত আপনার লেখা প্রতিটি প্রোগ্রাম উপর থেকে নিচে চলে শেষ হয়ে গেছে। একটি GUI (গ্রাফিকাল ইউজার ইন্টারফেস) অ্যাপ্লিকেশন আলাদা: এটি একটি উইন্ডো আঁকে, তারপর অপেক্ষা করে — কেউ কিছু ক্লিক না করা পর্যন্ত কিছুই করে না। এটাই event-driven প্রোগ্রামিং: আপনি ছোট ছোট ফাংশন ("callback") লিখেন যা নির্দিষ্ট event-এর সাড়ায় চলে, যেমন একটি বাটন ক্লিক।

tkinter হলো Python-এর বিল্ট-ইন GUI টুলকিট — কোনো অতিরিক্ত ইনস্টলেশনের প্রয়োজন নেই — যা এটিকে ডেস্কটপ অ্যাপ ডেভেলপমেন্টের স্বাভাবিক শুরুর জায়গা করে দেয়।

সিনট্যাক্স
import tkinter as tk
 
root = tk.Tk()
label = tk.Label(root, text="Hello")
label.pack()
root.mainloop()

উদাহরণ

আপনার প্রথম উইন্ডো খুব সহজ

আপনার প্রথম উইন্ডো
import tkinter as tk
 
root = tk.Tk()
root.title("My First App")
label = tk.Label(root, text="Hello, Tkinter!")
label.pack(padx=20, pady=20)
root.mainloop()
আউটপুট('Hello, Tkinter!' টেক্সট সহ একটি ছোট উইন্ডো খোলে)

Tk() মূল উইন্ডো তৈরি করে; .pack() একটি widget তার ভেতরে বসায়; mainloop() event loop শুরু করে যা উইন্ডোটিকে খোলা ও সাড়া-দেওয়ার মতো রাখে।

একটি callback সহ একটি বাটন সহজ

একটি callback সহ একটি বাটন
import tkinter as tk
 
def on_click():
    label.config(text="Button was clicked!")
 
root = tk.Tk()
label = tk.Label(root, text="Waiting...")
label.pack(pady=10)
button = tk.Button(root, text="Click me", command=on_click)
button.pack(pady=10)
root.mainloop()
আউটপুট(বাটন চাপলে লেবেলের টেক্সট 'Button was clicked!'-এ বদলে যায়)

command=on_click on_click-কে callback হিসেবে নিবন্ধন করে — বাটন ক্লিক হলেই এটি স্বয়ংক্রিয়ভাবে চলে। এটাই event-driven প্রোগ্রামিং।

একটি Entry ফিল্ড থেকে পড়া বাস্তব উদাহরণ

একটি Entry ফিল্ড থেকে পড়া
import tkinter as tk
 
def greet():
    name = entry.get()
    result_label.config(text=f"Hello, {name}!")
 
root = tk.Tk()
entry = tk.Entry(root)
entry.pack(pady=5)
tk.Button(root, text="Greet", command=greet).pack(pady=5)
result_label = tk.Label(root, text="")
result_label.pack(pady=5)
root.mainloop()
আউটপুট(একটি নাম টাইপ করে Greet ক্লিক করলে একটি ব্যক্তিগত শুভেচ্ছাবার্তা দেখায়)

entry.get() ঠিক বাটন ক্লিক হওয়ার মুহূর্তে Entry widget-এ ব্যবহারকারী যা টাইপ করেছেন তা পড়ে।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

root.mainloop() ভুলে গেলে উইন্ডো হয় কখনো দেখা যায় না বা তাৎক্ষণিক বন্ধ হয়ে যায়, কারণ সেটিকে বেঁচে রাখা event loop কখনো শুরুই হয় না।

✓ ভালো অভ্যাস
  • একটি tkinter স্ক্রিপ্ট সবসময় root.mainloop() দিয়ে শেষ করুন।
  • callback ফাংশন ছোট রাখুন — জটিল লজিকের জন্য অন্য ফাংশন কল করুন।
  • একটি container-এর ভেতরে .pack(), .grid(), বা .place() একইভাবে ব্যবহার করুন — মিশিয়ে দিলে বিভ্রান্তিকর লেআউট হতে পারে।
  • একটি বাটন callback-এর ভেতরে ঝুঁকিপূর্ণ কাজ try/except-এ মুড়িয়ে দিন, এবং পুরো অ্যাপ ক্র্যাশ না করে tkinter.messagebox দিয়ে এরর দেখান।

import tkinter as tk
from tkinter import messagebox
 
def show_message():
    messagebox.showinfo("You typed", entry.get())
 
root = tk.Tk()
root.title("Echo App")
entry = tk.Entry(root)
entry.pack(pady=5)
tk.Button(root, text="Show", command=show_message).pack(pady=5)
root.mainloop()

কুইজ

প্রতিটি প্রশ্নের উত্তর দিন, তারপর জমা দিয়ে নিজের স্কোর ও ব্যাখ্যা দেখুন।

1. কী একটি tkinter উইন্ডোর event loop শুরু করে?

root.start()
root.mainloop()
root.run()
এটি স্বয়ংক্রিয়ভাবে শুরু হয়
mainloop() উইন্ডোটিকে বন্ধ না হওয়া পর্যন্ত খোলা রাখে ও event শোনে।

2. event-driven প্রোগ্রামিংয়ে একটি 'callback' কী?

একটি event-এর সাড়ায় স্বয়ংক্রিয়ভাবে চলা একটি ফাংশন
একটি নির্দিষ্ট ধরনের ভ্যারিয়েবল
এক ধরনের লুপ
একটি এরর মেসেজ
একটি callback হলো এমন কোড যা কোনো নির্দিষ্ট event (যেমন একটি ক্লিক) ঘটলে চলার জন্য নিবন্ধিত।

3. একটি Entry widget-এ ব্যবহারকারী যা টাইপ করেছেন তা কীভাবে পড়বেন?

entry.text
entry.value
entry.get()
entry.read()
.get() একটি Entry widget থেকে বর্তমান টেক্সট বের করে আনে।

সারাংশ

  • tkinter হলো Python-এর বিল্ট-ইন GUI টুলকিট — কোনো অতিরিক্ত ইনস্টলেশনের প্রয়োজন নেই।
  • GUI প্রোগ্রাম event-driven: এগুলো mainloop()-এ অপেক্ষা করে এবং callback দিয়ে ব্যবহারকারীর কাজে সাড়া দেয়।
  • Label, Button, ও Entry হলো টেক্সট দেখানো, একটি কাজ চালু করা, ও ইনপুট নেওয়ার মূল widget।
  • একটি tkinter স্ক্রিপ্ট সবসময় root.mainloop() দিয়ে শেষ করুন।
