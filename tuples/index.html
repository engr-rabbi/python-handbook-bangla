মডিউল 07 — টাপল

একটি ক্রমিক সংগ্রহ, যা তৈরি হয়ে গেলে আর কখনো বদলানো যায় না।

পূর্বশর্ত: মডিউল ০৬ — লিস্ট

এই লেসন শেষে আপনি যা করতে পারবেন

  • প্যারেন্থিসিস দিয়ে টাপল তৈরি ও ইনডেক্স করা
  • টাপল কেন অপরিবর্তনীয় এবং কখন এটি গুরুত্বপূর্ণ তা ব্যাখ্যা করা
  • একটি ফাংশন থেকে একের বেশি মান রিটার্ন করতে টাপল ব্যবহার করা

ধারণা ও সিনট্যাক্স

একটি টাপল দেখতে ও কাজ করতে প্রায় ঠিক লিস্টের মতো — এটাও ক্রমিক, এবং আপনি একইভাবে ইনডেক্স ও স্লাইস করতে পারেন — একটি গুরুত্বপূর্ণ পার্থক্য বাদে: একবার তৈরি হয়ে গেলে, একটি টাপল বদলানো যায় না। না append, না item assignment, না remove।

এটা শুনতে একটা ডাউনগ্রেড মনে হতে পারে, কিন্তু অপরিবর্তনীয়তা আসলে একটি ফিচার: এটি বোঝায় "এই ডেটা বদলানো উচিত নয়", Python-কে সামান্য storage optimize করার সুযোগ দেয়, এবং — সবচেয়ে উপকারীভাবে — ঠিক এটাই ব্যবহার হয় যখন কোনো ফাংশন একাধিক মান রিটার্ন করে।

সিনট্যাক্স
point = (3, 4)
x, y = point   # unpacking
point[0]       # 3

উদাহরণ

একটি টাপল তৈরি ও ইনডেক্স করা খুব সহজ

একটি টাপল তৈরি ও ইনডেক্স করা
point = (3, 4)
print(point[0], point[1])
আউটপুট3 4

টাপল লিস্টের মতোই ইনডেক্সিংয়ের নিয়ম মেনে চলে — স্কয়ার ব্র্যাকেটের বদলে প্যারেন্থিসিসই একমাত্র দৃশ্যমান পার্থক্য।

টাপল অপরিবর্তনীয় সহজ

টাপল অপরিবর্তনীয়
colors = ("red", "green")
try:
    colors[0] = "blue"
except TypeError as e:
    print("Can't do that:", e)
আউটপুটCan't do that: 'tuple' object does not support item assignment

একটি আইটেম বদলাতে চাইলে TypeError দেখা দেয় — বাস্তবে 'অপরিবর্তনীয়' মানে ঠিক এটাই।

একাধিক মান রিটার্ন করা বাস্তব উদাহরণ

একাধিক মান রিটার্ন করা
def min_max(numbers):
    return min(numbers), max(numbers)
 
lowest, highest = min_max([4, 9, 1, 7])
print(lowest, highest)
আউটপুট1 9

return a, b আসলে একটি একক টাপল (a, b) রিটার্ন করে, যা আপনি সাথে সাথে দুটো ভ্যারিয়েবলে unpack করতে পারেন।

ভিজ্যুয়াল ব্যাখ্যা

💡 এটা কেন কাজ করে?

উপরের ধারণার ব্যাখ্যাটি আবার ধীরে ধীরে, লাইন বাই লাইন পড়ুন — সেখানকার প্রতিটি কিওয়ার্ড উদাহরণের কোডের একটি লাইনের সাথে সরাসরি মিলে যায়। এখনো পরিষ্কার না হলে, এই লেসনে ট্রেসড উদাহরণ থাকলে সেটি এক ধাপ এক ধাপ করে আবার চালিয়ে দেখুন।

🔍 ভেতরে ভেতরে কী ঘটে? (অ্যাডভান্সড)

ভেতরে ভেতরে, Python আপনার সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং একটি ভার্চুয়াল মেশিনে (CPython ইন্টারপ্রিটার) চালায়। ভ্যারিয়েবলগুলো একটি নেমস্পেস ডিকশনারিতে থাকা নাম, যা মেমরিতে থাকা অবজেক্টের দিকে নির্দেশ করে — উপরের ট্রেসারের মেমরি প্যানেলে ঠিক এটাই দেখানো হচ্ছে।

সাধারণ ভুল

✗ সাধারণ ভুল 1

একটি সিঙ্গেল-আইটেম টাপলের একটি ট্রেইলিং কমা লাগে — না থাকলে, Python এটাকে শুধু সাধারণ প্যারেন্থিসিস হিসেবে দেখে।

✗ এটি এড়িয়ে চলুন
এতে দেখা দেবে <class 'int'> প্রিন্ট করে, কোনো টাপল নয় — একটি নিঃশব্দ বাগ, ক্র্যাশ নয়
single = (5)
print(type(single))
✓ সঠিক পদ্ধতি
সংশোধিত
single = (5,)
print(type(single))
✓ ভালো অভ্যাস
  • যে ডেটা একটি নির্দিষ্ট কাঠামো বোঝায়, যেমন (x, y) কোঅর্ডিনেট বা (r, g, b) রং, তার জন্য টাপল ব্যবহার করুন।
  • ম্যানুয়াল ইনডেক্সিংয়ের বদলে যেখানে সম্ভব টাপল unpacking (a, b = my_tuple) ব্যবহার করুন।
  • আইটেম যোগ, বাদ বা reorder করার প্রয়োজন হলে টাপলের বদলে লিস্ট ব্যবহার করুন।

🏆 চ্যালেঞ্জ

circle_stats(radius) নামে একটি ফাংশন লিখুন যা (circumference, area)-এর একটি টাপল রিটার্ন করে, তারপর unpack করে দুটোই ২ দশমিক স্থান পর্যন্ত রাউন্ড করে প্রিন্ট করুন।

  • pi = 3.14159 ব্যবহার করুন
  • দুটো মানই একটি টাপল হিসেবে রিটার্ন করুন
  • ফলাফলটি দুটো নামযুক্ত ভ্যারিয়েবলে unpack করুন
💡 ইঙ্গিত প্রয়োজন?

circumference = 2 * pi * radius, area = pi * radius ** 2

🔍 একটি নমুনা সমাধান দেখুন
Python
def circle_stats(radius):
    pi = 3.14159
    return 2 * pi * radius, pi * radius ** 2
 
circ, area = circle_stats(5)
print(round(circ, 2), round(area, 2))

প্রতিটি প্রশ্নের উত্তর দিন, তারপর জমা দিয়ে নিজের স্কোর ও ব্যাখ্যা দেখুন।

1. লিস্ট ও টাপলের মূল পার্থক্য কী?

টাপল বেশি ডেটা টাইপ ধরে রাখতে পারে
টাপল অপরিবর্তনীয়, লিস্ট পরিবর্তনযোগ্য
লিস্ট প্যারেন্থিসিস ব্যবহার করে
আসলে কোনো পার্থক্য নেই
অপরিবর্তনীয়তাই মূল পার্থক্য।

2. 5 নিয়ে একটি একক আইটেমের টাপল কীভাবে লিখবেন?

(5)
(5,)
[5]
tuple(5)
একটি ট্রেইলিং কমা প্রয়োজন, নাহলে Python (5)-কে শুধু ইন্টিজার 5 ধরে নেয়।

3. একটি ফাংশন যদি `return a, b` করে, তাহলে কী হয়?

একটি সিনট্যাক্স এরর
কোনো সম্পর্ক না থাকা দুটো আলাদা মান রিটার্ন হয়
এটি একটি একক টাপল (a, b) রিটার্ন করে
শুধু a রিটার্ন হয়
কমা দিয়ে ভাগ করা রিটার্ন মান স্বয়ংক্রিয়ভাবে একটি টাপলে জমা হয়।

সারাংশ

  • টাপল লিস্টের মতোই ক্রমিক, কিন্তু তৈরি হওয়ার পর পরিবর্তন করা যায় না।
  • একটি সিঙ্গেল-আইটেম টাপলের একটি ট্রেইলিং কমা লাগে: (5,)।
  • ফাংশন সাধারণত একসাথে একাধিক মান রিটার্ন করতে টাপল ব্যবহার করে।
